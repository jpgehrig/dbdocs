#### new Or(filter1, filter2)

This is a combo filter that implements the logical "OR" operation of two
filters.

##### Parameters:

| Name      | Type                                    | Description                          |
|-----------|-----------------------------------------|--------------------------------------|
| `filter1` | [OM.filter.Filter](OM.filter.Filter.md) | The first OM.filter.Filter instance  |
| `filter2` | [OM.filter.Filter](OM.filter.Filter.md) | The second OM.filter.Filter instance |

##### Returns:

An instance of OM.filter.Or

Type
OM.filter.Or
