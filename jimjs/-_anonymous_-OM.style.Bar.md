#### new style.Bar(name, color)

This class represents the bar in a BarChart.

##### Parameters:

| Name    | Type   | Description              |
|---------|--------|--------------------------|
| `name`  | String | The bar name             |
| `color` | String | The bar color (#rrggbb). |

##### Returns:

An instance of OM.style.Bar

Type
OM.style.Bar
