#### new Xor(filter1, filter2)

This is a combo-filter class that implements the logical "XOR" operation of
two filters.

##### Parameters:

| Name      | Type                                    | Description                          |
|-----------|-----------------------------------------|--------------------------------------|
| `filter1` | [OM.filter.Filter](OM.filter.Filter.md) | The first OM.filter.Filter instance  |
| `filter2` | [OM.filter.Filter](OM.filter.Filter.md) | The second OM.filter.Filter instance |

##### Returns:

An instance of OM.filter.Xor

Type
OM.filter.Xor
