#### new Like(filterAtrribute, filterValue)

This is a filter class that implements the "Like" filter similar to the
SQL like clause.

##### Parameters:

| Name              | Type   | Description                                    |
|-------------------|--------|------------------------------------------------|
| `filterAtrribute` | String | The name of the feature attribute to be tested |
| `filterValue`     | String | The filtering attribute value                  |

##### Returns:

An instance of OM.filter.Like

Type
OM.filter.Like
