#### new OutputAddress()

OutputAddress is a validated output address.
For each match returned by the geocoder, there may be a validated output address. This object contains these properties:

- id : the id if specified in the address.
- name : name.
- houseNumber : house number.
- street : street
- settlement : city or builtup area
- municipality: name of municipality if applicable
- region: region where applicable
- country : country, typically an ISO2 code
- postalCode : postal code
- postalAddonCode : postal addon code
- side : side
- percent : percent
- edgeId : edgeId
