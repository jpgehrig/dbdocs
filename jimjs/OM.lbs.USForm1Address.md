#### new USForm1Address(options)

USForm1Address, US address format.

##### Parameters:

| Name      | Type   | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|-----------|--------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `options` | Object | This is an object literal that specifies the Address options. It can have the following properties.<br><br>• id {String} Optional. The id field is used to uniquely<br>distinguish an address in a batch geocoding request. It is optional<br>when geocoding a single address.<br><br>• country {String}. specify the 2-letter country ISO code; the<br>default value for “country” is always “US”<br><br>• name {String} Place name.<br><br>• street {String} Intersecting street names.<br><br>• intersectingStreet {String} Street address (house number, street name, etc.).<br><br>• lastline {String} lastline is City, state, zip code.<br><br><br>for example an option object:<br>{<br>name:"Oracle",<br>street:"500 Oracle Parkway",<br>lastline:Redwood City, CA, 94021<br>} |
