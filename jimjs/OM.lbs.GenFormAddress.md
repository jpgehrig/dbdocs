#### new GenFormAddress(options)

GenFormAddress, General (international) address format.

##### Parameters:

| Name      | Type   | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|-----------|--------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `options` | Object | This is an object literal that specifies the Address options. It can have the following properties.<br><br>• id {String} Optional. The id field is used to uniquely<br>distinguish an address in a batch geocoding request. It is optional<br>when geocoding a single address.<br><br>• country {String}. specify the 2-letter country ISO code; the<br>default value for “country” is always “US”<br><br>• name {String} Place name.<br><br>• street {String} Street address.<br><br>• intersectingStreet {String} Intersecting street names.<br><br>• subArea {String} Name of a sub-area within a city; big European cities may be divided into multiple smaller districts.<br><br>• city {String} City name.<br><br>• region {String} Region(state/province) name.<br><br>• postalCode {String} Postal code.<br><br>• postalAddonCode {String} Postal add-on code.<br><br><br>for example an option object:<br>{<br>id:"1",<br>street:"1 Oracle Drive",<br>city:"Nashua",<br>region:"NH",<br>postalCode:"03062",<br>country:"US"<br>} |
