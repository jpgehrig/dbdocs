#### new CollectionBucket(config)

This class defines a collection bucket

##### Parameters:

| Name     | Type   | Description                                                                                                                                                                                                                                                                         |
|----------|--------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `config` | Object | A config object with the following attributes:<br>• values {Array} The value list for this collection bucket.<br>• dataType {String} The data type for the values. Default is "string".<br>• keepWhiteSpace {boolean} Whether to keep white spaces in the values. Default is false. |

##### Returns:

An instance of OM.style.CollectionBucket
