#### new GdfFormAddress(options)

GdfFormAddress, GDF standard address format.

##### Parameters:

| Name      | Type   | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|-----------|--------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `options` | Object | This is an object literal that specifies the Address options. It can have the following properties.<br><br>• id {String} Optional. The id field is used to uniquely<br>distinguish an address in a batch geocoding request. It is optional<br>when geocoding a single address.<br><br>• country {String}. specify the 2-letter country ISO code; the<br>default value for “country” is always “US”<br><br>• name {String} Place name.<br><br>• street {String} Street address.<br><br>• intersectingStreet {String} Intersecting street names.<br><br>• builtupArea {String} GDF built-up-area name, equivalent to a US city.<br><br>• order8Area {String} GDF order8-area name, equivalent to a US county.<br><br>• order2Area {String} GDF order2-area name.<br><br>• order1Area {String} GDF order1-area name, equivalent to a US state.<br><br>• postalCode {String} Postal code.<br><br>• postalAddonCode {String} Postal add-on code.<br><br><br>for example an option object:<br>{<br>id:"1",<br>street:"1 Oracle Drive",<br>builtupArea:"Nashua",<br>order1Area:"NH",<br>postalCode:"03062",<br>country:"US"<br>} |
