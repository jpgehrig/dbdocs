#### new TileLayer(name, options)

This class represents a map tile layer served by an Oracle MapViewer
tile server. It contains the zoom level, scale, tile size and other relevant details
required to fetch and display the tiles..

##### Parameters:

| Name      | Type   | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
|-----------|--------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `name`    | String | The unique layer name.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `options` | Object | An object that specifies other tile layer parameters.<br>It can have the following attributes:<br><br>• dataSource {String}: The data source where the mapviewer tile layer is defined.<br>• tileLayer {String}: The name of mapviewer tile layer.<br>• tileServerURL {String}: The mapviewer tile server URL. For example, "http://maps.oracle.com/mapviewer/mcserver".<br>This is only needed when the tiles are not served by the mapviewer server specified by mapViewerURL passed<br>to the Map constructor.<br>• subdomains {Array}: Mapviewer subdomains array. These are used to fetch tiles from multiple subdomains.<br>Example: \['instance1', 'instance2', 'instance3'\] (Optional).<br>• tileImageURL {String}: The URL for local storaged tiles, this is only valide when creating a tilelayer from a local folder<br>• tileLayerConfig {OM.layer.TileLayerConfig}: The tile layer configuration object. This is required<br>only when the tile layer is an custom tile layer.<br>• getTileURL {Function}: A function that returns the tile image URL for a tile with the specified<br>zoom level and tile indices. The function takes the following parameters: zoomLevel,<br>tileX, tileY, tileBound. Where tileX and tuileY are the tile indices or IDs.<br>This is required only when the tile layer is an custom tile layer.<br>• isLocalTileLayer {Boolean}: specify whether it is a local tilelayer or not |

##### Returns:

An instance of OM.layer.TileLayer

Type
OM.layer.TileLayer

#### setZIndex()

Set the z-index for the layer.

Note: A valid layer z-index should be a number between 1 and n, where n is
the number of layers that are currently displayed in the map. When the newIndex
parameter of setZIndex is less than 1, it will be set to 1. If it is
greater than n, it will be set to n. If z-Index value, newIndex, is already assigned
to another layer, then it will still be assigned to the current layer (on which this function is invoked).
One or more of the other layer will be assigned a different z-index value. The changes will depend on
whether this layer was inserted into the current layer stack or just moved within the layer stack.

Inherited From:
- [OM.layer.Layer#setZIndex](OM.layer.Layer.md)

##### Returns:

The old z-index

Type
int
