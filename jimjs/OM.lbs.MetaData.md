#### new MetaData(elocURL)

MetaData is a class that provides capability and data coverage information for the
relevant services (mapping, geocoding and routing) on eLocation. For
instance one should be able to query if a specific country is supported
by the geocoding service.

##### Parameters:

| Name      | Type   | Description                                                                                                                                                           |
|-----------|--------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `elocURL` | string | the eLocation host base URL, which specifies the<br>host and application context root for the eLocation service.<br>The default value is http://elocation.oracle.com. |
