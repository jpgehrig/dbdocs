## Part III  Reference Information

This document has the following parts:

- [Conceptual and Usage Information](spatial-concepts-usage.md) provides conceptual and usage information about Oracle Spatial and Graph.

- [Spatial Web Services](spatial-web-services.md) provides conceptual and usage information about Oracle Spatial and Graph web services.

- Part III provides reference information about Oracle Spatial and Graph operators, functions, and procedures.

- [Supplementary Information](spatial-supplementary-information.md) provides supplementary information (appendixes and a glossary).

To understand the examples in the reference chapters, you must understand the conceptual and data type information in [Spatial Data Types and Metadata](spatial-datatypes-metadata.md), especially [SDO_GEOMETRY Object Type](spatial-datatypes-metadata.md).

- [SQL Statements for Indexing Spatial Data](sql-indexing-spatial-data.md)
  This chapter describes the SQL statements used when working with the spatial object data type.
- [Spatial Operators](spatial-operators-reference.md)
  This chapter describes the operators that you can use when working with the spatial object data type.
- [Spatial Aggregate Functions](spatial-aggregate-functions.md)
  This chapter contains reference and usage information for the spatial aggregate functions.
- [SDO_CS Package (Coordinate System Transformation)](SDO_CS-reference.md)
  The MDSYS.SDO_CS package contains subprograms for working with coordinate systems.
- [SDO_CSW Package (Catalog Services for the Web)](SDO_CSW-reference.md)
  The MDSYS.SDO_CSW package contains subprograms for various processing operations related to support for Catalog Services for the Web (CSW).
- [SDO_CSW_PROCESS Package \[deprecated\]](SDO_CSW_PROCESS-reference.md)
  The MDSYS.SDO_CSW_PROCESS package is deprecated.
- [SDO_GCDR Package (Geocoding)](SDO_GCDR-reference.md)
  The MDSYS.SDO_GCDR package contains subprograms for performing geocoding.
- [SDO_GEOM Package (Geometry)](SDO_GEOM-reference.md)
  The MDSIS.SDO_GEOM package contains subprograms for working with geometry objects.
- [SDO_LRS Package (Linear Referencing System)](SDO_LRS-reference.md)
  The MDSYS.SDO_LRS package contains subprograms that create, modify, query, and convert linear referencing elements.
- [SDO_MIGRATE Package (Upgrading)](SDO_MIGRATE-reference.md)
  The MDSYS.SDO_MIGRATE package contains a single subprogram, SDO_MIGRATE.TO_CURRENT.
- [SDO_OLS Package (OpenLS)](SDO_OLS-reference.md)
  The MDSYS.SDO_OLS package contains subprograms for Spatial and Graph OpenLS support.
- [SDO_PC_PKG Package (Point Clouds)](SDO_PC_PKG-reference.md)
  The MDSYS.SDO_PC_PKG package contains subprograms to support working with point clouds.
- [SDO_SAM Package (Spatial Analysis and Mining)](SDO_SAM-reference.md)
  The MDSYS.SDO_SAM package contains subprograms for spatial analysis and data mining.
- [SDO_TIN_PKG Package (TINs)](SDO_TIN_PKG-reference.md)
  The MDSYS.SDO_TIN_PKG package contains subprograms to support working with triangulated irregular networks (TINs).
- [SDO_TRKR Package (Location Tracking)](SDO_TRKR-reference.md)
  The MDSYS.SDO_TRKR package contains subprograms for using the location tracking server.
- [SDO_TUNE Package (Tuning)](SDO_TUNE-reference.md)
  The MDSYS.SDO_TUNE package contains subprograms for spatial tuning.
- [SDO_UTIL Package (Utility)](SDO_UTIL-reference.md)
  The MDSYS.SDO_UTIL package contains spatial utility subprograms.
- [SDO_WCS Package (Web Coverage Service)](SDO_WCS-reference.md)
  The MDSYS.SDO_WCS package contains subprograms associated with Oracle Spatial and Graph support for Web Coverage Service (WCS).
- [SDO_WFS_LOCK Package (WFS)](SDO_WFS_LOCK-reference.md)
  The MDSYS.SDO_WFS_LOCK package contains subprograms for WFS support for registering and unregistering feature tables.
- [SDO_WFS_PROCESS Package (WFS Processing)](SDO_WFS_PROCESS-reference.md)
  The MDSYS.SDO_WFS_PROCESS package contains subprograms for various processing operations related to support for Web Feature Services.
