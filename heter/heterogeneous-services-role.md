Oracle Database gateways are the synchronous solution for operating in a heterogeneous environment. The common component of Oracle Database gateways is Heterogeneous Services. This chapter describes the architecture and functionality of the Heterogeneous Services component and its interaction with Oracle Database gateways.

- [Heterogeneous Connectivity Process Architecture](heterogeneous-connectivity-process-architecture.md)
  The Heterogeneous Services component in Oracle Database communicates with a Heterogeneous Services agent process which, in turn, communicates with the non-Oracle system.
- [Heterogeneous Services Agents](heterogeneous-services-agents.md)
  A Heterogeneous Services agent is the process through which Oracle Database connects to a non-Oracle system.
- [Types of Heterogeneous Services Agents](heterogeneous-services-agent-types.md)
  There are two types of Heterogeneous Services agents.
- [Heterogeneous Services Components](heterogeneous-services-components.md)
  Heterogeneous Services in Oracle Database consists of a transaction service and a SQL service.
- [Heterogeneous Services Configuration Information](heterogeneous-services-configuration-information.md)
  Heterogeneous Services components consist of generic code and must be configured to work with many different non-Oracle systems.
- [Heterogeneous Services Data Dictionary](heterogeneous-services-data-dictionary.md)
  The agent uploads configuration information to the Heterogeneous Services component immediately after establishing a connection.
- [Process Flow for non-Oracle Database Queries](gateway-process-flow.md)
  There are a sequence of events that occur when a client application queries the non-Oracle database system through the gateway.
