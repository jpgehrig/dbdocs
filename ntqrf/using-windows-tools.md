You can use Windows tools in the following ways to manage Oracle Database:

- [Using Event Viewer to Monitor a Database](using-event-viewer-to-monitor-a-database.md)
  Event Viewer lets you monitor events in your system. An event is an important occurrence in the system or application (such as Oracle Database) that requires user notification.
- [Using Microsoft Management Console to Administer a Database](using-microsoft-management-console-to-administer-a-database.md)
  Microsoft Management Console provides a central location for network administration.
- [Using Registry Editor to Modify Configuration Information](using-registry-editor-to-modify-configuration-information.md)
  Oracle Database stores its configuration information in a structure known as the registry.
- [Using Task Manager to Monitor Applications and Processes](using-task-manager-to-monitor-applications-and-processes.md)
  Task Manager monitors applications and processes.
- [Using Local Users and Groups to Manage Users and Groups](using-local-users-and-groups-to-manage-users-and-groups.md)
  Local Users and Groups enable you to manage users and groups on Windows.
