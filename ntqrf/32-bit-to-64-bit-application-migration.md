Use Oracle 64-bit components to create your applications.

To migrate your business logic, refer to Migration Tips on the Microsoft Developer Network (MSDN) website at [`http://msdn.microsoft.com/en-us/library/windows/desktop/aa384214.aspx`](https://www.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/19/ntqrf&id=application_migration).

**Note:**

`NCHAR` columns in user tables are not changed during the migration.
