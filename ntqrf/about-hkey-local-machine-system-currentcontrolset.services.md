`HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet` contains the following keys:

- Control

- Enum

- HardwareProfiles

- Services

The first three are used by the operating system. You can edit only the `Services` subkey, which contains [Parameters for Oracle Database Services](parameters-for-oracle-database-services.md).

- [Parameters for Oracle Database Services](parameters-for-oracle-database-services.md)
  `HKEY_LOCAL_MACHINE\SYSTEM\CURRENTCONTROLSET\SERVICES` subkey contains additional subkeys that correspond to each Oracle Database service.
