You can start database tools in multiple Oracle homes.

If you have multiple Oracle homes on your computer from previous releases, then see Appendix B, "Optimal Flexible Architecture" in [Oracle Database Installation Guide for Microsoft Windows](../ntdbi/index.md) for a description of differences between Oracle homes in different releases.

- [Starting Tools from Multiple Oracle Homes](starting-tools-from-multiple-oracle-homes.md)
  Each Oracle home, including the first Oracle home you create on your computer, has a unique HOMENAME.
