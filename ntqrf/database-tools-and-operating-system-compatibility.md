The exception is Oracle SQL Developer is available only at Oracle Technology Network (OTN). See

[`http://www.oracle.com/technetwork/developer-tools/sql-developer/overview/index.html`](https://www.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/19/ntqrf&id=otn_sql_developer)
