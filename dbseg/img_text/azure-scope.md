# Description of the illustration azure-scope.png

Image azure-scope.png shows the Add a scope pane from Microsoft Azure AD. From top to bottom, right to left, are the following components:

The Add a scope label

The Scope name field, followed by the application URI and the scope that you enter

The Who can consent? label, followed by two toggles: Admins and users, and Admins only

The Admin consent display name field

The Admin consent description field

The User consent display name field

The User consent description

The State options, which are Enabled and Disabled
