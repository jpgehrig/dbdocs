# Description of the illustration azure-reg.png

Image azure-reg.png shows the Register an application pane from Microsoft Azure AD. From top to bottom, right to left, are the following components:

The label Register an application

The label Name, followed by the text "The user-facing display name for this application (this can be changed later).

A field for the Name label

The label Supported account types, followed by "Who can use this application or access this API"?

The following four options:

Accounts in this organizational directory (tenant-name only - Single tenant)

Accounts in any organizational directory (Any Azure AD directory - Multitenant)

Accounts in any organizational directory (Any Azure AD directory - Multitenant) and personal Microsoft accounts (e.g. Skype, Xbox)

Personal Microsoft accounts only

Following these four options, is the Help me choose button, a section on Redirect URI, the text "Register an app you're working on here. Integrate gallery apps and other apps from outside your organization by adding from Enterprise applications", and the Register button.
