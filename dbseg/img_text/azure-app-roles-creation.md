# Description of the illustration azure-app-roles-creation.png

Image azure-scope.png shows the App roles pane from Microsoft Azure AD. From top to bottom, right to left, are the following components:

The App roles label

The Create app role button and to its right, the "Got feedback?" link

A label saying "Got a second to give us some feedback?"

The App roles label, followed by the text "App roles are custom roles to assign permissions to users or apps. The application defines and publishes the app roles and interprets them as permissions during authorization."

The link "How do I assign App roles"

A table with the columns from left to right, Display name, Description, Allowed member types, Value, ID, State. The table shows one role, entitled dba_admin.
