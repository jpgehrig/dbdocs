The Select Upgrade Options window is displayed. It has three checkboxes to select upgrade options. You can select or unselect these options. The options are Enable Parallel Upgrade, Recompile Invalid Objects, and Upgrade Timezone Data. These options are explained in detail in the text following the image.

Below the upgrade options selections, there are two fields where you can specify your own custom SQL scripts that you want executed as part of the upgrade. There are two entry fields: Before Upgrade, and After Upgrade. These custom SQL script input fields are explained in detail in the following text.

In the window, there are Help, Back, Next, and Cancel buttons that you can select, which come after the upgrade options selection and input fields.
