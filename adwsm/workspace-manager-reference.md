This document has three parts:

- [Conceptual and Usage Information](workspace-manager-concepts-usage.md) provides conceptual and usage information about Workspace Manager.

- Part II provides reference information about the Workspace Manager PL/SQL API (DBMS_WM package) and static data dictionary views.

- [Supplementary Information](workspace-manager-supplementary-information.md) provides supplementary information (appendixes and a glossary).

Part II contains the following chapters with reference information:

- [DBMS_WM Package: Reference](DBMS_WM-reference.md)
  Workspace Manager includes PL/SQL subprograms (procedures and functions), in a package named `DBMS_WM`, that perform the available features of the product. This chapter provides reference information on each subprogram.
- [Workspace Manager Static Data Dictionary Views](workspace-manager-views.md)
  Workspace Manager creates and maintains static data dictionary views to hold information about such things as version-enabled tables, workspaces, savepoints, users, privileges, locks, and conflicts.
