# Description of the illustration cncpt342.eps

This graphic depicts four table partitions: SALES_1998, SALES_1999, SALES_2000, SALES_2001. The first and third partitions are labeled "INDEXING OFF." The second and fourth partitions are labeled "INDESING ON." An icon labeled "Global Index Partition p3" points to rows in the second partition. An icon labeled "Global Index Partition p2" points to rows in the second partition. An icon labeled "Global Index Partition p1" points to rows in the fourth partition.
