Shows the Collection Manager screen after pressing the Bulk Mapping button. There is a Import File section with a button to Upload Mapping(XML File), below this will be displayed files which have been previously uploaded, displaying their name, who uploaded it, when it was uploaded and an option to delete the XML.

There is also a Export Generated XML section with a button Generate XML File (Current Mapping). Below this is shown the most recent generated XML file for current mappings. Showing a link to download the file, the date it was generated and who it was generated by.
