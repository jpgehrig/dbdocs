Shows the Author Check screen after choosing to author a check type of OS available fields are:

- Audit check type

- On hold

- Audit check name

- OS command

- Oracle Version

- OS Command for report

- Platforms

- Candidates Systems

- Needs Running

- Oracle Executable Path

- Comparison Operator

- Comparison Value

- Alert Level

- Success Message

- Failure Message

- Benefit/Impact

- Risk

- Action/Repair

- User Comments

- Documentation Notes

- Links to documents

Clicking the title for any field will display field help.
