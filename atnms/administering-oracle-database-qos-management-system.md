This chapter describes the basic administrative tasks you perform when using Oracle Database QoS Management to manage performance of your Oracle RAC cluster.

- [Determining If Oracle Database QoS Management is Enabled](determining-if-qos-is-enabled.md)
  You enable Oracle Database QoS Management in a hierarchical-method.
- [Monitoring Performance with Oracle Database QoS Management](monitoring-performance-qos-management.md)
  After you have enabled Oracle Database QoS Management and created a default policy set, you can start to use Oracle Database QoS Management to monitor the performance of your system.
- [Using the Oracle Database QoS Management Dashboard](using-qos-management-dashboard.md)
  The Oracle Database QoS Management Dashboard (the Dashboard) provides an easy to use interface for managing the Oracle Database QoS Management system.
- [Administering the Policy Set](administering-policy-set.md)
  Whether you are configuring the Oracle Database QoS Management system for the first time, or want to create a new Policy Set, you use the Create Policy Set wizard to create your Policy Set.
- [Managing Performance Classes](managing-performance-classes.md)
  Each policy set contains one or more performance classes. Each performance class defines a type of workload on your servers.
- [Managing Performance Policies](managing-performance-policies.md)
- [Reviewing Performance Metrics](reviewing-performance-metrics.md)
  You can view a variety of performance metrics for the Oracle Database QoS Management system as a whole, or for individual Performance Classes.
- [Creating Administrative Users for Oracle Database QoS Management](creating-administrative-users-qos-management.md)
  Oracle Database QoS Management provides a command line utility named QOSCTL to help you manage users.
- [Editing the Resource Plan for Oracle Database QoS Management](editing-resource-plan-qos-management.md)
  You can perform limited editing of the Resource Manager plans used by Oracle Database Quality of Service Management.
