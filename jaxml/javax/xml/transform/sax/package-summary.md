# **Package javax.xml.transform.sax**

**This package implements SAX2-specific transformation APIs.**

**See: Description**

- **Interface Summary**

  | Interface                                   | Description                                                                                                                      |
  |---------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------|
  | [TemplatesHandler](TemplatesHandler.md)     | A SAX ContentHandler that may be used to process SAX parse events (parsing transformation instructions) into a Templates object. |
  | [TransformerHandler](TransformerHandler.md) | A TransformerHandler listens for SAX ContentHandler parse events and transforms them to a Result.                                |

- **Class Summary**

  | Class                                             | Description                                                                    |
  |---------------------------------------------------|--------------------------------------------------------------------------------|
  | [SAXResult](SAXResult.md)                         | Acts as an holder for a transformation Result.                                 |
  | [SAXSource](SAXSource.md)                         | Acts as an holder for SAX-style Source.                                        |
  | [SAXTransformerFactory](SAXTransformerFactory.md) | This class extends TransformerFactory to provide SAX-specific factory methods. |
