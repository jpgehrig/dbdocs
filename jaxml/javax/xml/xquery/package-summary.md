# **Package javax.xml.xquery**

- **Interface Summary**

  | Interface                                                   | Description                                                                                                                                                                                                                        |
  |-------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
  | [ConnectionPoolXQDataSource](ConnectionPoolXQDataSource.md) | A factory for `PooledXQConnection` objects.                                                                                                                                                                                        |
  | [PooledXQConnection](PooledXQConnection.md)                 | An object that provides hooks for connection pool management.                                                                                                                                                                      |
  | [XQConnection](XQConnection.md)                             | A connection (session) with a specific XQuery engine.                                                                                                                                                                              |
  | [XQConnectionEventListener](XQConnectionEventListener.md)   | An object that registers to be notified of events generated by a `PooledXQConnection` object.                                                                                                                                      |
  | [XQDataFactory](XQDataFactory.md)                           | This interface represents a factory to obtain sequences, item objects and types.                                                                                                                                                   |
  | [XQDataSource](XQDataSource.md)                             | An `XQDataSource` is a factory for `XQConnection` objects.                                                                                                                                                                         |
  | [XQDynamicContext](XQDynamicContext.md)                     | `XQDynamicContext` provides access to the dynamic context as defined in [*2.1.2 Dynamic Context, XQuery 1.0: An XML Query Language*](http://www.w3.org/TR/xquery/#eval_context).                                                   |
  | [XQExpression](XQExpression.md)                             | This interface describes the execute immediate functionality for expressions.                                                                                                                                                      |
  | [XQItem](XQItem.md)                                         | This interface represents an item in the XDM.                                                                                                                                                                                      |
  | [XQItemAccessor](XQItemAccessor.md)                         | This interface represents a common interface for accessing the values of an XQuery item.                                                                                                                                           |
  | [XQItemType](XQItemType.md)                                 | The `XQItemType` interface represents an item type as defined in [*XQuery 1.0: An XML Query language*](http://www.w3.org/TR/xquery).                                                                                               |
  | [XQMetaData](XQMetaData.md)                                 | `XQMetaData` interface provides information about the data source, in various aspects, such as the product name and version identification, supported features, specific behaviors, user information, product limits and so forth. |
  | [XQPreparedExpression](XQPreparedExpression.md)             | This interface describes an expression that can be prepared for multiple subsequent executions.                                                                                                                                    |
  | [XQResultItem](XQResultItem.md)                             | This interface represents an immutable item object obtained from an `XQResultSequence` using the `getItem` method.                                                                                                                 |
  | [XQResultSequence](XQResultSequence.md)                     | This interface represents a sequence of items obtained as a result of evaluation XQuery expressions.                                                                                                                               |
  | [XQSequence](XQSequence.md)                                 | This interface represents a sequence of items as defined in the XDM.                                                                                                                                                               |
  | [XQSequenceType](XQSequenceType.md)                         | The `XQSequenceType` interface represents a sequence type as [*XQuery 1.0: An XML Query language*](http://www.w3.org/TR/xquery).                                                                                                   |
  | [XQStaticContext](XQStaticContext.md)                       | An `XQStaticContext` represents default values for various [*XQuery Static Context Components*](http://www.w3.org/TR/xquery/#id_xq_static_context_components).                                                                     |

- **Class Summary**

  | Class                                           | Description                                                                                                                          |
  |-------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------|
  | [XQConnectionEvent](XQConnectionEvent.md)       | An event object that provides information about the source of a connection-related event.                                            |
  | [XQConstants](XQConstants.md)                   | `XQConstants` class provides constants that can be used in the XQJ API.                                                              |
  | [XQStackTraceElement](XQStackTraceElement.md)   | This class represents a frame in a stack trace, akin to the `java.lang.StackTraceElement` but for XQuery callstacks instead of Java. |
  | [XQStackTraceVariable](XQStackTraceVariable.md) | This class represents the list of variables and their values in an error stack.                                                      |

- **Exception Summary**

  | Exception                                       | Description                                                                                                                                         |
  |-------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------|
  | [XQCancelledException](XQCancelledException.md) | `XQCancelledException` is an exception to indicate that the current XQuery processing is cancelled by the application through a `cancel()` request. |
  | [XQException](XQException.md)                   | An exception that provides information on XQJ, XQuery or other errors reported by an XQJ implementation.                                            |
  | [XQQueryException](XQQueryException.md)         | An exception that provides information on errors occurring during the evaluation of an xquery.                                                      |
