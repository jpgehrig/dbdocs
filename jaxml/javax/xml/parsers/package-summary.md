# **Package javax.xml.parsers**

**Provides standard APIs for DOM 2.0 and SAX 1.0 parsers.**

**See: Description**

- **Class Summary**

  | Class                                               | Description                                                                                                           |
  |-----------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------|
  | [DocumentBuilder](DocumentBuilder.md)               | Defines the API to obtain DOM Document instances from an XML document.                                                |
  | [DocumentBuilderFactory](DocumentBuilderFactory.md) | Defines a factory API that enables applications to obtain a parser that produces DOM object trees from XML documents. |
  | [SAXParser](SAXParser.md)                           | Defines the API that wraps an `org.xml.sax.XMLReader` implementation class.                                           |
  | [SAXParserFactory](SAXParserFactory.md)             | Defines a factory API that enables applications to configure and obtain a SAX based parser to parse XML documents.    |

- **Exception Summary**

  | Exception                                                       | Description                              |
  |-----------------------------------------------------------------|------------------------------------------|
  | [ParserConfigurationException](ParserConfigurationException.md) | Indicates a serious configuration error. |

- **Error Summary**

  | Error                                                     | Description                                                                |
  |-----------------------------------------------------------|----------------------------------------------------------------------------|
  | [FactoryConfigurationError](FactoryConfigurationError.md) | Thrown when a problem with configuration with the Parser Factories exists. |
