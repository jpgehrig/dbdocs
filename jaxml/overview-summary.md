| Package                                                             | Description                                                                                                                                                                                                          |
|---------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

| [org.w3c.dom.traversal](org/w3c/dom/traversal/package-summary.md)   | A W3C standard package, that provides a framework of interfaces for implementing DOM level 2 Traversal feature for dynamically traversing the XML document.                                                          |
| [org.w3c.dom.validation](org/w3c/dom/validation/package-summary.md) | A W3C standard package of DOM level 3 Validation specification, that  provides guidance to programs and scripts to dynamically update the content and structure of documents, ensuring the validity of the document. |
