## **Package oracle.xdb Description**

**Packages oracle.xdb and oracle.xdb.dom implement the Java Document Object Model (DOM) API for XMLType. Java DOM API for XMLType implements the W3C DOM Recommendation Level 1.0 and Level 2.0 Core and also provides Oracle-specific extensions.**
