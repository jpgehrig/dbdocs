# **Package oracle.xml.jaxp**

**Provides implementation of JAXP standard.**

**See: Description**

- **Class Summary**

  | Class                                                   | Description                                                                                                           |
  |---------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------|
  | [JXDocumentBuilder](JXDocumentBuilder.md)               | Defines the API to obtain DOM Document instances from an XML document.                                                |
  | [JXDocumentBuilderFactory](JXDocumentBuilderFactory.md) | Defines a factory API that enables applications to obtain a parser that produces DOM object trees from XML documents. |
  | [JXSAXParser](JXSAXParser.md)                           | Defines the API that wraps an `org.xml.sax.XMLReader` implementation class.                                           |
  | [JXSAXParserFactory](JXSAXParserFactory.md)             | Defines a factory API that enables applications to configure and obtain a SAX-based parser to parse XML documents.    |
  | [JXSAXTransformerFactory](JXSAXTransformerFactory.md)   | A JXTransformerFactory instance can be used to create Transformer and Templates objects.                              |
  | [JXTransformer](JXTransformer.md)                       | An instance of this class transforms a Source into a Result.                                                          |
