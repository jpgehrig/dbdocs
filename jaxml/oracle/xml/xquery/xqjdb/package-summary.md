## **Package oracle.xml.xquery.xqjdb Description**

**Oracle XQJ implementation for use with XML DB. Provides the [`OXQDDataSource`](OXQDDataSource.md), which is an implementation of [`XQDataSource`](../../../../javax/xml/xquery/XQDataSource.md) and a starting point for using XQJ with XML DB.**
