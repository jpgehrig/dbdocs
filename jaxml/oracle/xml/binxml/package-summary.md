# **Package oracle.xml.binxml**

**Provides APIs for Binary XML encoding and decoding.**

**See: Description**

- **Interface Summary**

  | Interface                                               | Description                                                                                            |
  |---------------------------------------------------------|--------------------------------------------------------------------------------------------------------|
  | [BinXMLDecoder](BinXMLDecoder.md)                       | The interface for converting a binary stream into XML.                                                 |
  | [BinXMLEncoder](BinXMLEncoder.md)                       | An interface which contains APIs to convert XML to binary stream.                                      |
  | [BinXMLMetadataProvider](BinXMLMetadataProvider.md)     | This interface defines APIs for users to plug in a metadata repository used for encoding and decoding. |
  | [BinXMLProcessor](BinXMLProcessor.md)                   | A top level interface which represents the Binary XML Processor.                                       |
  | [BinXMLStream](BinXMLStream.md)                         | This interface represents the binary XML Stream object.                                                |
  | [DBBinXMLMetadataProvider](DBBinXMLMetadataProvider.md) | The interface implements the BinXMLMetadataProvider interface.                                         |

- **Class Summary**

  | Class                                                             | Description                                                                                                       |
  |-------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------|
  | [BinXMLMetadataProviderFactory](BinXMLMetadataProviderFactory.md) | Factory class for creating DBBinXMLMetadataProvider                                                               |
  | [BinXMLProcessorFactory](BinXMLProcessorFactory.md)               | Factory class to create a BinXMLProcessor object                                                                  |
  | [BinXMLSerializer](BinXMLSerializer.md)                           | The BinXMLSerializer class provides pull style serialization                                                      |
  | [BinXMLVocabId](BinXMLVocabId.md)                                 | This class is used to represent the vocabulary Id associated with each dtd or schema document as per the CSX RFC. |
  | [DBBinXMLMetadataProviderImpl](DBBinXMLMetadataProviderImpl.md)   |                                                                                                                   |

- **Exception Summary**

  | Exception                             | Description                                               |
  |---------------------------------------|-----------------------------------------------------------|
  | [BinXMLException](BinXMLException.md) | This class is used for all types of Binary XML Exceptions |
