# **Package oracle.xml.pipeline.controller**

**Provides an XML Pipeline controller which executes XML processes in an pipeline based on dependencies.**

**See: Description**

- **Interface Summary**

  | Interface                                       | Description                                                                                                                                             |
  |-------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------|
  | [PipelineConstants](PipelineConstants.md)       | This interface contains all the static constants for pipeline.controller.                                                                               |
  | [PipelineErrorHandler](PipelineErrorHandler.md) | For Pipeline Errors the application calling the Pipeline Processor must implement this interface to handle errors received from the Pipeline Processor. |

- **Class Summary**

  | Class                                     | Description                                                                                                                             |
  |-------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------|
  | [Input](Input.md)                         | This class represents an input object of a pipeline process.                                                                            |
  | [orapipe](orapipe.md)                     | The orapipe class provides a command-line interface to validate and execute the pipedoc for running connecting xml components together. |
  | [Output](Output.md)                       | This class represents an output object of a pipeline process.                                                                           |
  | [PipeDocElement](PipeDocElement.md)       | Abstract class to represent an element in the pipeline document.                                                                        |
  | [PipelineDoc](PipelineDoc.md)             | Encapsulates the pipeline doc, which forms the input to the pipeline execution.                                                         |
  | [PipelineProcessor](PipelineProcessor.md) | The top level class which executes the pipeline.                                                                                        |
  | [Process](Process.md)                     | Base class for all pipeline process definitions.                                                                                        |
