# **Package org.w3c.dom.validation**

**A W3C standard package of DOM level 3 Validation specification, that  provides guidance to programs and scripts to dynamically update the content and structure of documents, ensuring the validity of the document.**

**See: Description**

- **Interface Summary**

  | Interface                                       | Description                                                                                                                                                                 |
  |-------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
  | [CharacterDataEditVAL](CharacterDataEditVAL.md) | This interface extends the `NodeEditVAL` interface with additional methods for document editing.                                                                            |
  | [DocumentEditVAL](DocumentEditVAL.md)           | This interface extends the `NodeEditVAL` interface with additional methods for document editing.                                                                            |
  | [ElementEditVAL](ElementEditVAL.md)             | This interface extends the `NodeEditVAL` interface with additional methods for guided document editing.                                                                     |
  | [NodeEditVAL](NodeEditVAL.md)                   | This interface is similar to the \[[DOM Level 3 Core](http://www.w3.org/TR/2002/WD-DOM-Level-3-Core-20021022)\] `Node` interface, with methods for guided document editing. |

- **Exception Summary**

  | Exception                       | Description                                                                                |
  |---------------------------------|--------------------------------------------------------------------------------------------|
  | [ExceptionVAL](ExceptionVAL.md) | Some Validation operations may throw an `ExceptionVAL` as described in their descriptions. |
