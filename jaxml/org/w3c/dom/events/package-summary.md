# **Package org.w3c.dom.events**

**A W3C standard package, that supports the optional "Events", "UIEvents", "MouseEvents", "MutationEvents", and "HTMLEvents" features of the DOM Level 2 Recommendation.**

**See: Description**

- **Interface Summary**

  | Interface                         | Description                                                                                                                         |
  |-----------------------------------|-------------------------------------------------------------------------------------------------------------------------------------|
  | [DocumentEvent](DocumentEvent.md) | The `DocumentEvent` interface provides a mechanism by which the user can create an Event of a type supported by the implementation. |
  | [Event](Event.md)                 | The `Event` interface is used to provide contextual information about an event to the handler processing the event.                 |
  | [EventListener](EventListener.md) | The `EventListener` interface is the primary method for handling events.                                                            |
  | [EventTarget](EventTarget.md)     | The `EventTarget` interface is implemented by all `Nodes` in an implementation which supports the DOM Event Model.                  |
  | [MutationEvent](MutationEvent.md) | The `MutationEvent` interface provides specific contextual information associated with Mutation events.                             |

- **Exception Summary**

  | Exception                           | Description                                                                               |
  |-------------------------------------|-------------------------------------------------------------------------------------------|
  | [EventException](EventException.md) | Event operations may throw an `EventException` as specified in their method descriptions. |
