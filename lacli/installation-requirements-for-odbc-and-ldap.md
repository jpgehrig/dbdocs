## Installation Requirements for ODBC and LDAP

Review these topics to install Open Database Connectivity (ODBC) and Lightweight Directory Access Protocol (LDAP).

- [About ODBC Drivers and Oracle Database](about-odbc-drivers-and-oracle-database.md)
  Open Database Connectivity (ODBC) is a set of database access APIs that connect to the database, prepare, and then run SQL statements on the database.
- [Installing ODBC Drivers for Linux x86-64](installing-odbc-drivers-for-linux-x86-64.md)
  If you intend to install Oracle's ODBC driver, then you must also install the most recent ODBC Driver Manager for Linux.
- [About LDAP and Oracle Plug-ins](about-ldap-and-oracle-plug-ins.md)
  Lightweight Directory Access Protocol (LDAP) is an application protocol for accessing and maintaining distributed directory information services over IP networks.
- [Installing the LDAP Package](installing-the-ldap-package.md)
  LDAP is included in a default Linux operating system installation.
