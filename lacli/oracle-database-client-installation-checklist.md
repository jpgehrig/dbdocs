## 1 Oracle Database Client Installation Checklist

Use checklists to review system requirements, and to plan and carry out Oracle Database Client installation.

Oracle recommends that you use checklists as part of your installation planning process. Using checklists can help you to confirm that your server hardware and configuration meet minimum requirements for this release and can help you carry out a successful installation.

- [Server Hardware Checklist for Oracle Database Client Installation](server-hardware-checklist-for-oracle-database-client-installation.md)
  Use this checklist to check hardware requirements for Oracle Database Client installations.
- [Operating System Checklist for Oracle Database Client on Linux](operating-system-checklist-for-oracle-database-client-on-linux.md)
  Use this checklist to check minimum operating system requirements for Oracle Database Client.
- [Server Configuration Checklist for Oracle Database Client](server-configuration-checklist-for-oracle-database-client.md)
  Use this checklist to check minimum server configuration requirements for Oracle Database Client installations.
- [Oracle User Environment Configuration Checklist for Oracle Database Installation](oracle-user-environment-configuration-checklist-for-oracle-database-installation.md)
  Use this checklist to plan operating system users, groups, and environments for Oracle Database management.
- [Storage Checklist for Oracle Database Client](storage-checklist-for-oracle-database-client.md)
  Use this checklist to review storage minimum requirements and assist with configuration planning.
- [Installer Planning Checklist for Oracle Database Client](installer-planning-checklist-for-oracle-database-client.md)
  Use this checklist to assist you to be prepared before starting Oracle Universal Installer.
