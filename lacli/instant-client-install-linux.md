## Installing Oracle Instant Client Packages

Learn the different methods to install Oracle Instant Client on Linux x86-64 and Linux for Arm (aarch64) platforms.

- [Installing Oracle Instant Client Using Zip Files](install-instant-client-using-zip.md)
  Learn how to download and use zip files to install Oracle Instant Client on Linux x86-64 and Linux for Arm (aarch64) platforms.
- [Installing Oracle Instant Client Using RPMs](install-instant-client-using-rpm.md)
  Learn how to install Oracle Instant Client on Linux x86-64 and Linux for Arm (aarch64) platforms by downloading the RPMs using the `dnf install` or the `yum install` command.
- [Installing Oracle Instant Client Using the Setup Wizard](running-oui-instant-client.md)
  Use the `runInstaller` command to start the Oracle Instant Client installation.
