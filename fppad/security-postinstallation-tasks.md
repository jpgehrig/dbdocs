## Oracle Fleet Patching and Provisioning Security Postinstallation Tasks

Perform these postinstallation tasks to make your Oracle Fleet Patching and Provisioning Server secure.

- [Authentication Options for Oracle Fleet Patching and Provisioning Operations](authentication-options-for-oracle-fpp.md)
  Some RHPCTL commands show authentication choices as an optional parameter.
- [Oracle Fleet Patching and Provisioning Roles](oracle-fpp-roles.md)
  An administrator assigns roles to Oracle Fleet Patching and Provisioning users with access-level permissions defined for each role.
- [Managing the Fleet Patching and Provisioning Client Password](managing-oracle-fpp-client-password.md)
  The Oracle Fleet Patching and Provisioning (Oracle FPP) Client uses a password stored internally to authenticate itself with the RHP server.
- [Oracle Fleet Patching and Provisioning Server Auditing](oracle-fpp-server-auditing.md)
  The Oracle Fleet Patching and Provisioning Server records the processing of all Oracle Fleet Patching and Provisioning operations, and also records whether those operations succeeded or failed.
