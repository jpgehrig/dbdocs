## Upgrading Oracle Fleet Patching and Provisioning Server

Upgrade Oracle Fleet Patching and Provisioning Server to the latest release to use the new features.

- [Starting Oracle FPP Server After Manually Upgrading Oracle Grid Infrastructure](starting-oracle-fpp-server-after-manual-gi-software-upgrade.md)
  If you upgrade Oracle Grid Infrastructure manually, without using Oracle Fleet Patching and Provisioning (Oracle FPP) self upgrade feature, then Oracle FPP Server does not start after the upgrade.
