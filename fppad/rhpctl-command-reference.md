## RHPCTL Command Reference

This section describes RHPCTL command usage information, and lists and describes RHPCTL commands.

- [audit Commands](audit-commands.md)
  Use commands with the `audit` keyword to delete, modify, and query audit records.
- [client Commands](client-commands.md)
  Use commands with the `client` keyword to add, delete, and manage Oracle Fleet Patching and Provisioning clients.
- [credentials Commands](credentials-commands.md)
  Use commands with the `credentials` keyword to add credentials to and delete credentials from the Oracle Cluster Registry (OCR).
- [database Commands](database-commands.md)
  Use commands with the `database` keyword to add, delete, move, and upgrade databases.
- [datapatch Commands](datapatch-commands.md)
  Use commands with the `datapatch` keyword to apply patches to the specified Oracle Database.
- [exadata Commands](exadata-commands.md)
  Use commands with the `exadata` keyword to patch an Oracle Exadata system.
- [gihome Commands](gihome-commands.md)
  Use commands with the `gihome` keyword to add or delete nodes to Oracle Grid Infrastructure home and, move and upgrade Oracle Grid Infrastructure home.
- [image Commands](image-commands.md)
  Use commands with the `image` keyword to add, delete, import, and manage gold images.
- [imagetype Commands](imagetype-commands.md)
  Use commands with the `imagetype` keyword to add, delete, modify, and manage an image type.
- [job Commands](job-commands.md)
  Use commands with the `job` keyword to delete or query schedule jobs.
- [osconfig Commands](osconfig-commands.md)
  Use commands with the `osconfig` keyword to backup, compare, and manage operating system configuration information.
- [patch Commands](patch-commands.md)
  Use commands with the `patch` keyword to apply or rollback one-off patches to the specified working copy using the in-place patching method.
- [peerserver Commands](peerserver-commands.md)
  Use commands with the `peerserver` keyword to display information for a peer server.
- [updateadvisor Commands](updateadvisor-commands.md)
  Use commands with the `updateadvisor` keyword to manage the user registered for the Oracle Update Advisor.
- [role Commands](role-commands.md)
  Use commands with the `role` keyword to add, delete, and manage roles.
- [series Commands](series-commands.md)
  Use commands with the `series` keyword to add, delete, subscribe, and manage a series.
- [server Commands](server-commands.md)
  Use commands with the `server` keyword to export, register, unregister, and query Oracle Fleet Patching and Provisioning Server.
- [user Commands](user-commands.md)
  Use commands with the `user` keyword to delete, modify, register, and unregister users.
- [useraction Commands](useraction-commands.md)
  Use commands with the `useraction` keyword to add, delete, and modify user actions.
- [workingcopy Commands](workingcopy-commands.md)
  Use commands with the `workingcopy` keyword to create, update, extend, and delete working copies.
