## Copying Oracle ASM Password File For Oracle RAC One Node Database

After installing Oracle RAC One Node database, copy the Oracle ASM password file, if configured, to all candidate nodes configured for fail over, unless you use shared password files stored in Oracle ASM.

If you install Oracle RAC One Node database using Database Configuration Assistant (DBCA), you need not perform this task since DBCA copies the Oracle ASM password file to a shared location.
