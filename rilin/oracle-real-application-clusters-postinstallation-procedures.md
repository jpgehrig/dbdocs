## 4  Oracle Real Application Clusters Postinstallation Procedures

Review this information to complete the postinstallation tasks after you have installed Oracle Real Application Clusters (Oracle RAC).

**Note:**

This chapter describes only basic configurations. Refer to [Oracle Database Administrator's Guide](../admin/getting-started-with-database-administration.md), and the product administration and tuning guides for more detailed configuration and tuning information. Refer also to [Oracle Database Installation Guide](../install-and-upgrade.md) for your platform for additional postinstallation configuration information.

- [Required Postinstallation Tasks](required-postinstallation-tasks.md)
  Download and apply required patches for your software release after completing your initial installation.
- [Recommended Postinstallation Tasks](recommended-postinstallation-tasks.md)
  Oracle recommends that you complete these tasks after installation.
- [Product-Specific Postinstallation Tasks](product-specific-postinstallation-tasks.md)
  You must complete postinstallation tasks before you can use some Oracle Database features.
- [Enabling and Disabling Oracle Database Options After Installation](enabling-and-disabling-oracle-database-options-after-installation.md)
  The `chopt` tool changes your database options after installation.
