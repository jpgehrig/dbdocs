## Net Service Names Created by DBCA

DBCA creates net service names for connections.

- [Net Service Names for Database Connections](net-service-names-for-database-connections.md)
  Clients that connect to any instance of Oracle RAC use the SCAN in the connect descriptor. You can also use net service names to connect to Oracle RAC.
- [Net Service Names for Instance Connections](net-service-names-for-instance-connections.md)
  Clients that connect to a particular instance of the database use the net service name for the instance.
