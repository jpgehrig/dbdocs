## A Using Scripts or Response Files to Create Oracle RAC Databases

Review this information for noninteractive installations during which you can create Oracle Real Application Clusters (Oracle RAC) databases using scripts.

**Note:**

The scripts generated by Database Configuration Assistant (DBCA) are for reference only. Oracle strongly recommends that you use DBCA to create a database.

- [Using DBCA to Generate Installation Scripts for Oracle RAC](using-dbca-to-generate-installation-scripts-for-oracle-rac.md)
  Review this topic to generate scripts to create an Oracle RAC database, create a database using the generated scripts, and prepare the database for use.
- [About DBCA Noninteractive (Silent) Configuration for Oracle RAC](about-dbca-noninteractive-silent-configuration-for-oracle-rac.md)
  You can perform a noninteractive, or silent configuration of Oracle RAC using DBCA. To perform a silent configuration, you must have completed an Oracle Grid Infrastructure (Oracle Clusterware and Oracle ASM) installation, run the `root.sh` script from the Oracle Database home, and defined the Oracle home directory environment variable.
- [Using DBCA Commands for Noninteractive (Silent) Configuration for Oracle RAC](using-dbca-commands-for-noninteractive-silent-configuration-for-oracle-rac.md)
  Review this topic for the command syntax to create an Oracle RAC database using DBCA.
- [How Response Files Work](how-response-files-work.md)
  Response files can assist you with installing an Oracle product multiple times on multiple computers.
- [Preparing Response Files](preparing-response-files.md)
  Review this information to prepare response files for use during silent mode or response file mode installations.
- [Running Oracle Universal Installer Using a Response File](running-oracle-universal-installer-using-a-response-file.md)
  After creating the response file, run Oracle Universal Installer at the command line, specifying the response file you created, to perform the installation.
- [Postinstallation Configuration Using Response File Created During Installation](postinstallation-configuration-using-response-file-created-during-installation.md)
  Use response files to configure Oracle software after installation. You can use the same response file created during installation to also complete postinstallation configuration.
- [Postinstallation Configuration Using the ConfigToolAllCommands Script](postinstallation-configuration-using-a-different-response-file.md)
  You can create and run a response file configuration after installing Oracle software. The `configToolAllCommands` script requires users to create a second response file, of a different format than the one used for installing the product.
- [Running Configuration Assistants Using Response Files](running-configuration-assistants-using-response-files.md)
  You can run configuration assistants in response file or silent mode to configure and start Oracle software after it is installed on the system. To run configuration assistants in response file or silent mode, you must copy and edit a response file template.
