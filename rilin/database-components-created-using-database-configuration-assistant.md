## Database Components Created Using Database Configuration Assistant

Understand the database components that DBCA creates.

- [About Tablespaces and Data Files](about-tablespaces-and-data-files.md)
  For both single-instance and cluster database environments, Oracle Database is divided into smaller logical areas of space known as tablespaces.
- [About Control Files](about-control-files.md)
  The database is configured with two control files that must be stored on shared storage.
- [About Online Redo Log Files](about-online-redo-log-files.md)
  Each database instance must have at least two online redo log files.
