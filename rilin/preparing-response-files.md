## Preparing Response Files

Review this information to prepare response files for use during silent mode or response file mode installations.

- [Editing a Response File Template](editing-a-response-file-template.md)
  Oracle provides response file templates for each product and each configuration tool.
- [Recording Response Files](recording-response-files.md)
  You can use OUI in interactive mode to record response files, which you can then edit and use to complete silent mode or response file mode installations. This method is useful for Advanced or software-only installations.
