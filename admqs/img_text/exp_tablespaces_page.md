This is a screenshot of the Tablespaces page. Below the heading Tablespaces from left to right are the Actions list, the View list, the Create button, the Drop button, and the Add Datafile button. To the far right is the Permanent field and the search section, which contains the Tablespace Name search field.

Below the search section is a table of tablespaces in the database. The table columns are: Name, Size, Free Space, Used(%), Auto Extend, Maximum Size, Status, Type, Group Name, Auto Segment Management, and Directory.
