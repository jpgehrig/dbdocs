This is a screenshot of the SGA Advisor graph on the Memory Management page in EM Express. The SGA Advisor graph appears on the Memory Management page when automatic shared memory management mode is enabled for the database. The horizontal axis of the graph is labeled sga_target (MB) and shows possible values for the SGA_TARGET initialization parameter. The horizontal axis starts with a value of 0 and displays values for the SGA_TARGET initialization parameter in 200 MB increments up to 1200 MB. The vertical axis of the graph is labeled Estimated Percentage of Time Saved. The vertical axis starts with a value of -80 and decreases in 20% increments to 0. An orange line on the graph plots possible values for the SGA_TARGET initialization parameter. The current setting for the SGA_TARGET initialization parameter is shown by a blue dot near the 600 MB value.
