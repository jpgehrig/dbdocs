This is a screenshot of the Memory Advisor graph on the Memory Management page in EM Express. The Memory Advisor graph appears on the Memory Management page when automatic memory management mode is enabled for the database. The horizontal axis of the graph is labeled memory_target (MB) and shows possible values for the MEMORY_TARGET initialization parameter. The horizontal axis starts with a value of 0 and displays values for the MEMORY_TARGET initialization parameter in 200 MB increments up to 1200 MB. The vertical axis of the graph is labeled Estimated Percentage of Time Saved. The vertical axis starts with a value of -28 and decreases in 6% increments to 0. An orange line on the graph plots possible values for the MEMORY_TARGET initialization parameter. The current setting for the MEMORY_TARGET initialization parameter is shown by a blue dot near the 600 MB value.
