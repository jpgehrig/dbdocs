## Enabling Oracle Instant Client Code Signing

Starting with Oracle Database Client 19c (19.22), you can verify the code sign for Oracle Instant Client zips to ensure the integrity of the packages before you deploy them in your environments.

- [Verifying Signed Oracle Instant Client Zip Files](verifying-signed-oracle-instant-client-zip-files.md)
  Use the Java utility `jarsigner` to verify the integrity of your Oracle Instant Client zip files.
