## Downloading Oracle Software

Select the method you want to use to download the software.

Download the installation files from either the Oracle Technology Network (OTN) or the Oracle Software Delivery Cloud portal and extract them on your hard disk. Ensure that you review and understand the terms of the license.

- [Downloading the Installation Archive Files from OTN](downloading-the-installation-archive-files-from-otn.md)
  Download installation archive files from Oracle Technology Network (OTN).
- [Downloading the Software from Oracle Software Delivery Cloud](downloading-software-from-otn.md)
  You can download the software from Oracle Software Delivery Cloud as Media Packs.
