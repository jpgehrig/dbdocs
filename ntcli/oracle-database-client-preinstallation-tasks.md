## 2 Oracle Database Client Preinstallation Tasks

Learn about the tasks that you must complete before you start Oracle Universal Installer.

- [Oracle Database Client Minimum Hardware Requirements](oracle-database-client-minimum-hardware-requirements.md)
  Learn about the hardware component and hard disk space requirements.
- [Oracle Database Client Software Requirements](oracle-database-client-software-requirements.md)
  Learn about the Oracle Database Client software requirements.
- [Creating Oracle Home User](creating-oracle-home-user.md)
  During Oracle Database Client installation, you can specify an optional Oracle Home User associated with the Oracle home.
- [Creating Users, Groups and Environments for Oracle Database Client](operating-system-groups-for-oracle-database-client-installations.md)
  Before installation, create operating system groups, users, and configure user environments.
- [Managing User Accounts with User Account Control](managing-user-accounts-with-user-account-control.md)
  To ensure that only trusted applications run on your computer, the Windows operating systems supported for Oracle Database Client provide User Account Control.
- [Remote Desktop Services](remote-desktop-services.md)
  Oracle supports installing, configuring, and running Oracle Database Client through Remote Desktop Services.
- [Microsoft Windows Servicing Options](microsoft-windows-servicing-options.md)
  On Microsoft Windows 10 systems, Microsoft introduced new servicing options.
- [Default Share Configuration Requirement](default-share-configuration-requirement.md)
  The prerequisite checks during Oracle Database Client installation require that the system drive on your computer has default share configured on it.
- [Installation Requirements for Web Browsers](installation-requirements-for-web-browsers.md)
  Web browsers are required only if you intend to use Oracle Enterprise Manager Database Express and Oracle Enterprise Manager Cloud Control. Web browsers must support JavaScript, and the HTML 4.0 and CSS 1.0 standards.
- [Microsoft Hyper-V Requirements](microsoft-hyperv-requirements.md)
  Microsoft Hyper-V enables you to create and manage a virtualized computing environment by running multiple operating systems simultaneously on a single computer and isolate operating systems from each other.
- [Enabling Oracle Instant Client Code Signing](enabling-oracle-instant-client-code-signing.md)
  Starting with Oracle Database Client 19c (19.22), you can verify the code sign for Oracle Instant Client zips to ensure the integrity of the packages before you deploy them in your environments.
