## A Installing Java Access Bridge

Learn how to install Java Access Bridge 2.0.2.

Java Access Bridge 2.0.2 enables use of a screen reader with Oracle components.

- [Overview of Java Access Bridge 2.0.2](overview-of-java-access-bridge.md)
  Java Access Bridge 2.0.2 enables assistive technologies to read Java applications running on the Windows platform.
- [Setting Up Java Access Bridge 2.0.2](setting-up-java-access-bridge.md)
  Learn how to install and configure Java Access Bridge 2.0.2 for Windows after installing Oracle components.
