## Operating System Checklist for Oracle Database Client Installation

Use this checklist to check minimum operating system requirements for Oracle Database Client.

Table 1-2 Operating System Checklist for Oracle Database Client Installation on Microsoft Windows

| Item                                  | Task                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
|:--------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Operating system general requirements | Oracle Database Client for Windows x64 is supported on the following operating system versions:<br>• Windows 8.1 x64 - Pro and Enterprise editions<br>• Windows 10 x64 - Pro, Enterprise, and Education editions<br>• Windows 11 x64 - Pro, Enterprise, and Education editions<br>• Windows Server 2012 R2 x64 - Standard, Datacenter, Essentials, and Foundation editions<br>• Windows Server 2016 x64 - Standard, Datacenter, and Essentials editions<br>• Windows Server 2019 x64 - Standard, Datacenter, and Essentials editions<br>• Windows Server 2022 x64 - Standard, Datacenter, and Essentials editions<br>• Windows Server 2025 x64 - Standard, Datacenter, and Essentials editions<br>**Note:**<br>Windows 11 x64 - Pro, Enterprise, and Education editions and Windows Server 2022 x64 - Standard, Datacenter, and Essentials editions are supported starting with Oracle Database 19c Release Update (19.13) or later. |
