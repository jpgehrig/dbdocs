## Installing the Oracle Database Client Software

These topics explain how to run the Setup Wizard to perform most database client installations.

- [Running Setup Wizard to Install Oracle Database Client](running-oracle-universal-installer-to-install-oracle-database-client.md)
  Use the `runInstaller` command to start the Oracle Database Client installation.
- [Installing Oracle Database Client Using Image File](installing-oracle-database-client-using-image-files.md)
  Extract the image software (client_home.zip) into the directory where you want your Oracle Database Client home to be located.
- [Using Oracle Net Configuration Assistant](using-oracle-net-configuration-assistant.md)
  Run Oracle Net Configuration Assistant in standalone mode after the Oracle Database Client installation is complete to configure the listener, naming methods, net service names, and directory server usage.
