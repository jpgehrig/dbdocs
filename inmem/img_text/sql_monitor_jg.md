This screenshot shows the Monitored SQL Execution Details page. The Overview section has the following subsections: General, Time & Wait Statistics, and IO Statistics. General shows the SQL text, execution times, and so on. Time & Wait Statistics show the duration and DB time. IO Statistics shows the buffer gets and I/O requests.

The Details section at the bottom has tabs for Plan Statistics (selected), Plan, and Activity. The Plan Statistics tab shows the execution plan. Step 3 is a hash join. A binoculars icon, called out in a red square, is on this line.
