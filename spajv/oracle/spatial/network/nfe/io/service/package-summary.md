# Package oracle.spatial.network.nfe.io.service

Provides the NFE services to perform operations related to NFE model, feature layers, analysis and workspace management.

See: Description

- **Interface Summary**

  | Interface                                         | Description                                                                                               |
  |---------------------------------------------------|-----------------------------------------------------------------------------------------------------------|
  | [NFEAnalysisIOService](NFEAnalysisIOService.md)   | This interface is the entry point to the feature analysis operations supported by NFE.                    |
  | [NFEFeatureIOService](NFEFeatureIOService.md)     | The feature service provides methods to load and manage the model features.                               |
  | [NFEIOService](NFEIOService.md)                   | This interface defines methods supported by the NFE services to access the NFE model and the data source. |
  | [NFEIOServiceProvider](NFEIOServiceProvider.md)   | This interface defines the single entry point to access NFE services.                                     |
  | [NFEModelIOService](NFEModelIOService.md)         | The model service provides methods to load, create and manage the model infrastructure.                   |
  | [NFEWorkspaceIOService](NFEWorkspaceIOService.md) | This interface defines methods related to model workspace management.                                     |
