# Package oracle.spatial.network.nfe.io.jdbc.dao

Provides the data access objects implementations; it is not recommended to use the data access objects methods, instead use the NFE services.

See: Description

- **Class Summary**

  | Class                           | Description                                                                                            |
  |---------------------------------|--------------------------------------------------------------------------------------------------------|
  | [AbstractDAO](AbstractDAO.md)   | A base class for data access objects (DAOs), providing methods to access the model and the connection. |
  | [FeatureDAO](FeatureDAO.md)     | The FeatureDAO data access object provides methods to load and manage the model features.              |
  | [ModelDAO](ModelDAO.md)         | The ModelDAO data access object provides methods to load, create and manage the model infrastructure.  |
  | [NetworkDAO](NetworkDAO.md)     | The NetworkDAO data access object provides methods to load, create and manage the network elements.    |
  | [RuleDAO](RuleDAO.md)           | The RuleDAO data access object provides methods to load, create and manage the NFE rules.              |
  | [SpatialDAO](SpatialDAO.md)     | The SpatialDAO data access object provides methods to load, create and manage spatial related data.    |
  | [WorkspaceDAO](WorkspaceDAO.md) | The WorkspaceDAO data access object provides methods related to the model workspace management.        |
