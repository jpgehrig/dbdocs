# Package oracle.spatial.network.nfe.model.rule

Provides memory representations of NFE rules and contains classes used to manage and enforce such rules.

See: Description

- **Class Summary**

  | Class                                                 | Description                                                                                                                   |
  |-------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------|
  | [NFECardinalityRule](NFECardinalityRule.md)           | Represents a cardinality rule associated to a feature layer and (optionally) a point feature class                            |
  | [NFEConnectivityRule](NFEConnectivityRule.md)         | Basic representation of a connectivity rule which defines the properties and methods common to all the NFE connectivity rules |
  | [NFELineLineRule](NFELineLineRule.md)                 | A representation of an NFE line-line connectivity rule                                                                        |
  | [NFELinePointRule](NFELinePointRule.md)               | A representation of an NFE line-point connectivity rule                                                                       |
  | [NFERuleInstance](NFERuleInstance.md)                 | Represents a materialization of a rule.                                                                                       |
  | [NFERuleInstanceRelation](NFERuleInstanceRelation.md) | Represents a relationship between a rule instance and a feature element to which the rule instance's rule was applied.        |
  | [NFERulesEngine](NFERulesEngine.md)                   | NFE component in charge of enforcing connectivity and cardinality rules.                                                      |
  | [NFERulesModel](NFERulesModel.md)                     | NFE component used as a holder and manager of rules.                                                                          |
