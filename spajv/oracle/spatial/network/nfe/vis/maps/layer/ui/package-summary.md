# Package oracle.spatial.network.nfe.vis.maps.layer.ui

Multiple layer implementations

See: Description

- **Interface Summary**

  | Interface                                 | Description                                                                                                                                                                                                                        |
  |-------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
  | [ShapeDrawingLayer](ShapeDrawingLayer.md) | An interface for layers that use a tool to create a shape and draw it For example, rectangle selection, rectangle zoom box and rectangular polygon creation layers can use the same RectangleTool if they implement this interface |

- **Class Summary**

  | Class                                               | Description                                                                                                                                                   |
  |-----------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------|
  | [MapNavLayer](MapNavLayer.md)                       | MapNavLayer renders and handles the events for the Navigation Panel that includes a panning dial, zoom buttons, and if a tile layer is present, a zoom slider |
  | [PointerLocationLayer](PointerLocationLayer.md)     | This layer displays helpful information related to the current mouse cursor, such as the ground coordinates.                                                  |
  | [ProgressIndicatorLayer](ProgressIndicatorLayer.md) | This layer displays a (indeterminate) progress indicator in the center of the map.                                                                            |
  | [ScaleBarLayer](ScaleBarLayer.md)                   | A background layer that sits at the bottom of layer stack, and intercepts primarily mouse wheel zooming and mouse panning events.                             |
