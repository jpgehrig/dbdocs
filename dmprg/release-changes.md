Changes in this release for Oracle Data Mining User’s Guide.

### Oracle Data Mining User's Guide

- This guide was introduced in release 12c. Oracle Data Mining User's Guide replaces two manuals that were provided in previous releases: Oracle Data Mining Administrator's Guide and Oracle Data Mining Application Developer's Guide.

- Information about database administration for Oracle Data Mining is now consolidated in [Administrative Tasks for Oracle Data Mining](administrative-tasks.md) . The remaining chapters of this guide are devoted to application development.

### Changes in Oracle Data Mining 19c

The following changes are documented in Oracle Data Mining User’s Guide for 19c.

#### Deprecated Features

The following features are deprecated in this release, and may be desupported in another release. See [Oracle Database Upgrade Guide](../upgrd/oracle-database-changes-deprecations-desupports.md) for a complete list of deprecated features in this release.

- `*GET_MODEL_DETAILS` are deprecated and are replaced with Model Detail Views. See [Model Detail Views](model-detail-views.md).

#### Desupported Features

See [Oracle Database Upgrade Guide](../upgrd/oracle-database-changes-deprecations-desupports.md) for a complete list of desupported features in this release.

#### Other Changes

The following is an additional change in Oracle Data Mining User’s Guide for 19c:

- "Enabling or Disabling a Database Option" topic is removed from the publication as the information is obsolete.

- [Exporting and Importing Mining Models](exporting-importing-mining-models.md) chapter is updated.

- Moved “[Outlier Treatment](embedding-transformations-model.md)” topic under "Oracle Data Mining Transformation Routines" topic.
