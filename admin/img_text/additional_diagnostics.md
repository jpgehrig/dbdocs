# Description of the illustration additional_diagnostics.gif

This graphic is a screen shot. It shows three tabs: Dump Files, Checker Findings, and Additional Diagnostics (selected). Underneath is a Run button. The table has the following columns: Select, Name, Description, Recommended, and Status. The row has a select button, SQL Test Case Builder, SQL Test Case Builder gathers and exports all the objects referenced by the SQL so that the problem can be reproduced, Yes, and a check mark.
