This illustration shows Oracle ACFS storage layers.

At the top are Oracle RAC, Oracle Database, and client applications.

The middle layer includes Oracle Clusterware, Oracle ASM, Oracle Automatic Storage Management Cluster File System (Oracle ACFS) file system, third-party file systems, and Oracle ASM Dynamic Volume Manager (Oracle ADVM).

The layer at the bottom shows the Oracle ASM disk group and the files it may contain.
