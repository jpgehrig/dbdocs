## Supported Oracle Linux 9 Distributions for x86-64

Use the following information to check supported Oracle Linux 9 distributions:

Table 4-1 x86-64 Oracle Linux 9 Minimum Operating System Requirements

|:-------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| SSH Requirement                      | Ensure that OpenSSH is installed on your servers. OpenSSH is the required SSH software.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Oracle Linux 9                       | Starting with Oracle Database 19c Release 19.19, the following minimum versions are supported:<br>• Oracle Linux 9 with the Unbreakable Enterprise Kernel 7: 5.15.0-1.43.4.2.el9uek.x86_64 or later<br>• Oracle Linux 9 with the Red Hat Compatible Kernel: 5.14.0-70.22.1.0.2.el9_0.x86_64 or later<br>Note: Oracle recommends that you update Oracle Linux to the latest available version and release level.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Packages for Oracle Linux 9          | Subscribe to the Oracle Linux 9 channel on the Unbreakable Linux Network, or configure a yum repository from the Oracle Linux yum server website, and then install the Oracle Database Preinstallation RPM, `oracle-database-preinstall-19c`. The Oracle Database Preinstallation RPM, `oracle-database-preinstall-19c`, automatically installs all required packages listed in the table below, their dependencies for Oracle Grid Infrastructure and Oracle Database installations, and also performs other system configuration. If you install the Oracle Database Preinstallation RPM, `oracle-database-preinstall-19c`, then you do not have to install these packages, as the Oracle Database Preinstallation RPM automatically installs them.<br>Install the latest released versions of the following packages:<br><br>bc<br>binutils<br>compat-openssl11<br>elfutils-libelf<br>fontconfig<br>glibc<br>glibc-devel<br>ksh<br>libaio<br>libasan<br>liblsan<br>libX11<br>libXau<br>libXi<br>libXrender<br>libXtst<br>libxcrypt-compat<br>libgcc<br>libibverbs<br>libnsl<br>librdmacm<br>libstdc++<br>libxcb<br>libvirt-libs<br>make<br>policycoreutils<br>policycoreutils-python-utils<br>smartmontools<br>sysstat<br>Note: If you intend to use 32-bit client applications to access 64-bit servers, then you must also install (where available) the latest 32-bit versions of the packages listed in this table. |
