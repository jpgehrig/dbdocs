## Deploying Oracle Database with Oracle Memory Speed

Learn the steps to use Oracle Memory Speed (OMS) in Oracle Database.

- [Enabling the OMS ODM Library](enable-oms-odm-library.md)
  Oracle routes I/O requests to the Oracle Memory Speed (OMS) file system through the Oracle Disk Manager (ODM) library.
- [Turning-Off the OMS ODM Library](turnoff-oms-odm-library.md)
  Learn how to turn off the ODM library.
- [Verifying HugePages Behavior in XFS Files](hugepages-in-xfs-files.md)
  For best performance, map the data files placed in DAX-enabled storage in to the virtual address space using HugePages mappings. For a memory-mapped file, set up the virtual-to-physical address translations when the pages are first touched.
