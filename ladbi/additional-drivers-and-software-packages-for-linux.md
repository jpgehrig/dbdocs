## Additional Drivers and Software Packages for Linux

Information about optional drivers and software packages.

You are not required to install additional drivers and packages, but you may choose to install or configure these drivers and packages.

- [Installing PAM for Login Authentication on Linux](installing-pam-for-login-authentication-on-linux.md)
  Pluggable Authentication Modules (PAM) is a system of libraries that handle user authentication tasks for applications.
- [Installing OCFS2](installing-ocfs2.md)
  You can use Oracle Cluster File System 2 (OCFS2) with Oracle Grid Infrastructure. However, you are not required to use OCFS2.
- [Installing Oracle Messaging Gateway](installing-oracle-messaging-gateway.md)
  Oracle Messaging Gateway is installed with Enterprise Edition of Oracle Database. However, you may require a CSD or Fix Packs.
- [Installation Requirements for ODBC and LDAP](installation-requirements-for-odbc-and-ldap.md)
  Review these topics to install Open Database Connectivity (ODBC) and Lightweight Directory Access Protocol (LDAP).
- [Installation Requirements for Programming Environments for Linux](installation-requirements-for-programming-environments-for-linux.md)
  Review the following section to install programming environments:
- [Installation Requirements for Web Browsers](installation-requirements-for-web-browsers.md)
  Web browsers are required only if you intend to use Oracle Enterprise Manager Database Express and Oracle Enterprise Manager Cloud Control. Web browsers must support JavaScript, and the HTML 4.0 and CSS 1.0 standards.
