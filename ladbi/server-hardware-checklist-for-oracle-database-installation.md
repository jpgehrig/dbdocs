## Server Hardware Checklist for Oracle Database Installation

Use this checklist to check hardware requirements for Oracle Database.

Table 1-1 Server Hardware Checklist for Oracle Database Installation

| Check                             | Task                                                                                                                                                              |
|:----------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Runlevel                          | 3 or 5                                                                                                                                                            |
| Server Display Cards              | At least 1024 x 768 display resolution, which Oracle Universal Installer requires.                                                                                |
| Minimum network connectivity      | Server is connected to a network                                                                                                                                  |
| Minimum RAM                       | • At least 1 GB RAM for Oracle Database installations. 2 GB RAM recommended.<br>• At least 8 GB RAM for Oracle Grid Infrastructure installations.                 |
| Linux for Arm (aarch64) processor | Oracle Database 19c Linux for Arm (aarch64) requires a CPU capable of Neoverse N1. Oracle recommends using a server with an Ampere Altra or Ampere Altra Max CPU. |
