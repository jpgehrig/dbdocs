# Description of the illustration em_red_pol_exp_create.png

Image em_red_pol_exp_create.png shows the Create dialog box of the Data Redaction Expressions page. From top to bottom, left to right, are the following components:

- Expression Name field, which is mandatory

- Description field, which is mandatory

- Expression field, which is mandatory. To the right of the Expression field is the Policy Expression Builder icon.

- At the lower right corner, the OK and Cancel buttons
