# Description of the illustration em_red_sensitive_col_types.png

Image em_red_sensitive_col_types.png shows the Add dialog box that appears when you click Add under Object Columns of the Create Data Redaction Policy page. For the purposes of this topic, the Redaction Format field shows U.S. Social Security Numbers — NUMBER. The list, when expanded, shows a large number of Data Redaction formats from which you can choose.
