# Description of the illustration asoag_pb_001b.png

Image asoag_pb_001b.png illustrates the different types of keystores in a tree chart formation, top to bottom, left to right:

- The top shows the label Keystore

- Under Keystore are two sub-types, Software Keystore and Hardware Keystore.

- Under Software Keystore are the sub-types Auto-Login Keystore, Local Auto-Login Keystore, and Password-Protected Keystore.

- Under Hardware Keystore are the sub-types Hardware Security Module (HSM) and Oracle Key Vault (OKV).
