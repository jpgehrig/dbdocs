# Description of the illustration em_red_pol_expr_edit.png

Image em_red_pol_expr_edit.png shows the Expression tab contents of the Data Redaction page. From left to right, top to bottom, are the following components:

- The tabs Policies, Expressions, and Formats

- The buttons View, Format, Create, Create Like, Edit, View, Delete, and Refresh

- A table with the columns Expression Name, Description, and Expression

- Two rows in this table, with one of the rows selected
