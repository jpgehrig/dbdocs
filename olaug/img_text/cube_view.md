Units Cube View: This screen capture of the General subpage of UNITS_CUBE_VIEW shows a crosstab describing the columns of the view. The view contains a row for every dimension and every measure, and columns for Column Name, Data Type, Object Type, and Dimension. TIME, CHANNEL, CUSTOMER, and PRODUCT columns have a data type of VARCHAR2, are DIMENSION object types, and have dimensions with the same names as the columns. UNITS, SALES, and COST columns have a data type of NUMBER and are MEASURE object types.
