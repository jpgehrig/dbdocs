# Description of the illustration policies_home_page.png

Image policies_home_page.png shows the Policies home page. The components of this image are as follows, from top to bottom, left to right:

The Policies label

Text describing what Database Vault policies are

A search field, with the label Policy Name, then a search field, and the Go button.

Instructions that say, “The search returns all matches beginning with the string you enter. You can use the wildcard symbol (%) in the search string.”

A command list, from the left to right: View, Create, View, Edit, Delete, and Show Oracle defined policies. (These are described later in this procedure.)

A table listing any existing policies, with the columns Name, Status, and Description.
