This manual describes Oracle Data Mining, a comprehensive, state-of-the-art data mining capability within Oracle Database. This manual presents the concepts that underlie the procedural information that is presented in [Oracle Data Mining User’s Guide](../dmprg/data-mining-SQL.md).

The preface contains these topics:

- Audience

- Documentation Accessibility

- Related Documentation

- Conventions

### Audience

Oracle Data Mining Concepts is intended for anyone who wants to learn about Oracle Data Mining.
