Part II provides basic conceptual information about the mining techniques that the Oracle Data Mining supports.

Mining techniques represent a class of mining problems that can be solved using data mining algorithms.

Part II contains these chapters:

- [Regression](regression.md)

- [Classification](classification.md)

- [Anomaly Detection](anomaly-detection.md)

- [Clustering](clustering.md)

- [Association](association.md)

- [Feature Selection and Extraction](feature-selection-extraction.md)

- [Time Series](time-series.md)

**Note:**

The term mining technique has no relationship to a SQL language technique.
