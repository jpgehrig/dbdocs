Changes in this release for Oracle Data Mining Concepts.

### Changes in Oracle Data Mining 19c

The following changes are documented in Oracle Data Mining Concepts for 19c.

#### Deprecated Features

The following features are deprecated in this release, and may be desupported in another release. See [Oracle Database Upgrade Guide](../upgrd/oracle-database-changes-deprecations-desupports.md) for a complete list of deprecated features in this release.

- `*GET_MODEL_DETAILS` are deprecated and are replaced with Model Detail Views. See [Oracle Data Mining User’s Guide](../dmprg/model-detail-views.md).

#### Desupported Features

See [Oracle Database Upgrade Guide](../upgrd/oracle-database-changes-deprecations-desupports.md) for a complete list of desupported features in this release.

#### Other Changes

The following is an additional change in Oracle Data Mining Concepts for 19c:

Throughout the document, "mining function(s)" were replaced with "mining technique(s)" to distinguish between a mining methodology and an API or SQL function.
