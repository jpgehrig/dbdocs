## 1 Oracle Database Installation Checklist

Use checklists to review system requirements, and to plan and carry out Oracle Database installation.

Oracle recommends that you use checklists as part of your installation planning process. Using a checklist ensures that your server hardware and configuration meets minimum requirements for this release, and enables you to carry out a successful installation.

- [Server Hardware Checklist for Oracle Database Installation](server-hardware-checklist-oracle-database-installation.md)
  Use this checklist to check hardware requirements for Oracle Database.
- [Operating System Checklist for Oracle Database Installation on Microsoft Windows](operating-system-checklist-oracle-database-installation-microsoft-windows.md)
  Use this checklist to check minimum operating system requirements for Oracle Database.
- [Server Configuration Checklist for Oracle Database Installation](server-configuration-checklist-for-oracle-database-installation.md)
  Use this checklist to check minimum server configuration requirements for Oracle Database installations.
- [Storage Checklist for Oracle Database Installation](storage-checklist-for-oracle-database-installation.md)
  Use this checklist to review storage minimum requirements and assist with configuration planning.
- [Oracle User Environment Configuration Checklist for Oracle Database Installation](user-environment-checklist-windows.md)
  Use this checklist to plan operating system users, groups, and environments for Oracle Database management.
- [Installer Planning Checklist for Oracle Database Installation](installer-planning-checklist.md)
  Use the checklist to assist you to be prepared before starting Oracle Universal Installer.
