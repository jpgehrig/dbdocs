## Configuring PL/SQL External Procedures

Configuring PL/SQL depends on the network configuration files used.

In nearly all cases, configuration is automatic. However, if you are using pre-8.0.3 `tnsnames.ora` and `listener.ora` files with your 19c database, then you must manually configure them.
