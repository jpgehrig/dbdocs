## C Installing and Configuring Oracle Database Using Response Files

Learn how to install and configure Oracle products using response files.

- [How Response Files Work](how-response-files-work.md)
  Response files can assist you with installing an Oracle product multiple times on multiple computers.
- [Using Response Files](using-response-files.md)
  Review this information to use response files.
- [Preparing a Response File](preparing-a-response-file.md)
  Learn about the methods that you can use to prepare a response file for use during silent-mode or response file-mode installations.
- [Running Oracle Universal Installer Using the Response File](running-oracle-universal-installer-using-the-response-file.md)
  At this stage, you are ready to run Oracle Universal Installer at the command line, specifying the response file you created, to perform the installation.
- [Running Net Configuration Assistant Using a Response File](running-net-configuration-assistant-using-a-response-file.md)
  When you run Net Configuration Assistant with a response file, you run it in a silent mode.
- [Running Oracle Database Configuration Assistant Using a Response File](running-oracle-database-configuration-assistant-using-a-response-file.md)
  You can run Oracle Database Configuration Assistant (Oracle DBCA) in a silent or a response file mode to configure and start an Oracle database on your system.
- [Postinstallation Configuration Using Response File Created During Installation](postinstallation-configuration-using-response-file-created-during-installation.md)
  To run a response file configuration after installing Oracle software:
- [Postinstallation Configuration Using the ConfigToolAllCommands Script](postinstallation-configuration-using-the-configtoolallcommands-script.md)
  You can create and run a response file configuration after installing Oracle software. The `configToolAllCommands` script requires users to create a second response file, of a different format than the one used for installing the product.
- [Using the Installation Response File for Postinstallation Configuration](using-the-installation-response-file-for-postinstallation-configuration.md)
  Starting with Oracle Database 12c release 2 (12.2), you can use the response file created during installation to also complete postinstallation configuration.
