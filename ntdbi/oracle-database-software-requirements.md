## Oracle Database Software Requirements

The following table lists the software requirements for Oracle Database on Windows x64:

Table 2-3 Windows x64 Software Requirements

| Requirement            | Value                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|:-----------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Operating System       | Oracle Database for Windows x64 is supported on the following operating systems:<br>• Windows 8.1 x64 - Pro and Enterprise editions<br>• Windows 10 x64 - Pro, Enterprise, and Education editions<br>• Windows 11 x64 - Pro, Enterprise, and Education editions<br>• Windows Server 2012 R2 x64 - Standard, Datacenter, Essentials, and Foundation editions<br>• Windows Server 2016 x64 - Standard, Datacenter, and Essentials editions<br>• Windows Server 2019 x64 - Standard, Datacenter, and Essentials editions<br>• Windows Server 2022 x64 - Standard, Datacenter, and Essentials editions<br>• Windows Server 2025 x64 - Standard, Datacenter, and Essentials editions<br>Note: <br>• Windows Multilingual User Interface Pack is supported.<br>• The Server Core option is not supported.<br>• Windows 11 x64 - Pro, Enterprise, and Education editions and Windows Server 2022 x64 - Standard, Datacenter, and Essentials editions are supported starting with Oracle Database 19c Release Update (19.13) or later. |
| Virtualization         | Oracle certifies the following virtualization technologies with Oracle Database on Windows:<br>• Oracle VM Server<br>• Microsoft Hyper-V<br>For more detailed information on certified Oracle VM Server combinations, check My Oracle Support note 464754.1. For more information on certified Hyper-V combinations, you can visit:<br><http://www.oracle.com/technetwork/database/virtualizationmatrix-172995.html>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Compiler and SDK       | The following component is supported only with Microsoft Visual C++ 2013 Update 5:<br>• Pro\*C/C++: Use Microsoft Visual C++ 2013 to convert the Pro\*C/C++ files into C/C++ files, and then use Microsoft Visual C++ 2017 Update 6 Version 15.6.3 or later to further build them.<br>The following components are supported with the compilers based on Microsoft Visual C++ 2017 Update 6 or later and Intel C++ 17.0 Update 8, and Microsoft Visual C++ 2017 Update 6 or later SDK:<br>• Oracle Call Interface (OCI)<br>• External callouts<br>• Oracle XML Developer's Kit (XDK)<br>• Oracle C++ Call Interface (OCCI)<br>Pro\*COBOL supports:<br>• Micro Focus Visual COBOL Version 6                                                                                                                                                                                                                                                                                                                                     |
| Network Protocol       | The Oracle Net foundation layer uses Oracle protocol support to communicate with the following industry-standard network protocols:<br>• TCP/IP<br>• TCP/IP with SSL<br>• Named Pipes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Oracle Database Client | To connect to Oracle Database 19c, the following are required:<br>• Oracle Database Client is version 11.2.0.4 or later.<br>• If the earlier Oracle Database Client is running on the same computer as Oracle Database 19c, then you cannot use a bequeath connection.<br>Oracle recommends upgrading Oracle Database Client to the latest patchset (11.2.0.4 or later). You can download the patchset from the Patches and Updates section of My Oracle Support at<br>`https://support.oracle.com`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Unzip utility          | Unzip 6.0 or later.<br>Unzip is required to extract the image files for Oracle Database and Oracle Grid Infrastructure installations.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
