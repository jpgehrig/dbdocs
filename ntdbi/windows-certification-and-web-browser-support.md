## Windows Certification and Web Browser Support

Review the Windows Certification and Web Browser Support information.

- [Remote Desktop Services](remote-desktop-services.md)
  Oracle supports installing, configuring, and running Oracle Database through Remote Desktop Services on Windows.
- [Microsoft Windows Servicing Options](microsoft-windows-servicing-options.md)
  On Microsoft Windows 10 systems, new servicing options are available.
- [Installation Requirements for Web Browsers](installation-requirements-for-web-browsers.md)
  Web browsers are required only if you intend to use Oracle Enterprise Manager Database Express and Oracle Enterprise Manager Cloud Control. Web browsers must support JavaScript, and the HTML 4.0 and CSS 1.0 standards.
- [Default Share Configuration Requirement](default-share-configuration-requirement.md)
  The prerequisite checks during Oracle Database installation require that the system drive on your computer has default share configured on it.
