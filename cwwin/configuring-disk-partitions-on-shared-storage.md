## Configuring Disk Partitions on Shared Storage

Use the disk administration tools provided by the operating system or third-party vendors to create disk partitions.

You can create the disk partitions using either the Disk Management Interface or the DiskPart utility, both of which are provided by the operating system.

- [Creating Disk Partitions Using the Disk Management Interface](creating-disk-partitions-using-the-disk-management-interface.md)
  Use the graphical user interface Disk Management snap-in to manage disks.
- [Creating Disk Partitions using the DiskPart Utility](creating-disk-partitions-using-the-diskpart-utility.md)
  You can also use the DiskPart utility to manage disks.
