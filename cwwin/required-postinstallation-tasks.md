## Required Postinstallation Tasks

Certain postinstallation tasks are critical for your newly installed software.

**Note:**

Backing up a voting file is no longer required.

- [Downloading Release Update Patches](downloading-and-installing-patch-updates.md)
  Download and install Release Updates (RU) and Monthly Recommended Patches (MRPs) patches for your Oracle software after you complete installation.
- [Configuring Exceptions for the Windows Firewall](configuring-exceptions-for-the-windows-firewall.md)
  To enable Oracle software to accept connection requests, you must configure the Windows Firewall by either opening up specific static transmission control protocol (TCP) ports in the firewall or by creating exceptions for specific executable files so they can receive connection requests on any ports they choose.
