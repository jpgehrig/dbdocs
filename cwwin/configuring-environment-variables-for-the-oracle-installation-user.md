## Configuring Environment Variables for the Oracle Installation User

The installer uses environment variables set for the Oracle Installation User.

- Before starting the Oracle Grid Infrastructure installation, ensure that you have correctly set the `%TEMP%` environment variable. Also, ensure that you have set the variable to the same value on all cluster nodes.
