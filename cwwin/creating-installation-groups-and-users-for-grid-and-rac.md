## Creating Installation Groups and Users for Oracle Grid Infrastructure and Oracle RAC

To install Oracle Grid Infrastructure and Oracle RAC, you must have an installation user and optionally an Oracle Home User.

**Note:**

During an Oracle Grid Infrastructure installation, both Oracle Clusterware and Oracle Automatic Storage Management (Oracle ASM) are installed. You no longer can have separate Oracle Clusterware installation owners and Oracle ASM installation owners.

- [About the Oracle Installation User](about-the-oracle-installation-user.md)
  The Oracle Installation User can be either a local user or a domain user.
- [About the Oracle Home User for the Oracle Grid Infrastructure Installation](about-the-oracle-home-user-for-the-oracle-grid-infrastructure-installation.md)
  During installation of Oracle Grid Infrastructure, you can specify an optional Oracle Home user for Grid Infrastructure Management Repository configuration.
- [About the Oracle Home User for the Oracle RAC Installation](about-the-oracle-home-user-for-the-oracle-rac-installation.md)
  The Oracle Home User for Oracle RAC can be different from the Oracle Home User you specified during the Oracle Grid Infrastructure installation.
- [When to Create an Oracle Home User](when-to-create-an-oracle-home-user.md)
  You must create an Oracle Home User in certain circumstances.
- [Oracle Home User Configurations for Oracle Installations](oracle-home-user-configurations-for-oracle-installations.md)
  When the Oracle software installation completes, you will have one of the following configurations:
- [Understanding the Oracle Inventory Directory and the Oracle Inventory Group](understanding-the-oracle-inventory-directory-and-the-oracle-inventory-group.md)
  You must have a group whose members are given access to write to the Oracle Inventory directory, which is the central inventory record of all Oracle software installations on a server.
