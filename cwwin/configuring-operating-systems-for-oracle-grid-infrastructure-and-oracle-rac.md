## 3 Configuring Operating Systems for Oracle Grid Infrastructure and Oracle RAC

Complete operating system configuration requirements and checks before you start the Oracle Grid Infrastructure installation.

- [Reviewing Operating System and Software Upgrade Best Practices](reviewing-operating-system-and-software-upgrade-best-practices.md)
  Review the general planning guidelines and platform-specific information about upgrades and migration.
- [Reviewing Operating System Security Common Practices](reviewing-operating-system-security-common-practices.md)
  Secure operating systems are an important basis for general system security.
- [Verifying Privileges for Copying Files in the Cluster](verify-privileges-for-copying-files-in-the-cluster.md)
  During installation, OUI copies the software from the local node to the remote nodes in the cluster. The installation user must have privileges on the other nodes in the cluster to copy the files.
- [Identifying Software Requirements](identifying-software-requirements.md)
  Depending on the products that you intend to install, verify that the required operating system software is installed on each node of your cluster.
- [Windows Firewall Feature on Windows Servers](windows-firewall-feature-on-windows-servers.md)
  When installing Oracle Grid Infrastructure software or Oracle RAC software on Windows servers, it is mandatory to disable the Windows Firewall feature.
- [Checking the Operating System Version](checking-the-operating-system-version.md)
  To determine whether your computer is running a 64-bit (x64) Windows operating system, perform these steps.
- [Checking Hardware and Software Certification on My Oracle Support](checking-hardware-and-software-certification-on-my-oracle-support.md)
  The My Oracle Support website also provides compatible client and database releases, patches, and workaround information for bugs.
- [Installation Requirements for Web Browsers](installation-requirements-web-browsers.md)
  Web browsers are required only if you intend to use Oracle Enterprise Manager Database Express and Oracle Enterprise Manager Cloud Control. Web browsers must support JavaScript, and the HTML 4.0 and CSS 1.0 standards.
