## 10 Oracle Grid Infrastructure Postinstallation Tasks

Complete the postinstallation tasks after you have installed the Oracle Grid Infrastructure software.

You are required to complete some configuration tasks after Oracle Grid Infrastructure is installed. In addition, Oracle recommends that you complete additional tasks immediately after installation. You must also complete product-specific configuration tasks before you use those products.

**Note:**

This chapter describes basic configuration only. Refer to product-specific administration and tuning guides for more detailed configuration and tuning information.

- [Required Postinstallation Tasks](required-postinstallation-tasks.md)
  Certain postinstallation tasks are critical for your newly installed software.
- [Recommended Postinstallation Tasks](recommended-postinstallation-tasks.md)
  Oracle recommends that you complete these tasks as needed after installing Oracle Grid Infrastructure.
- [Using Earlier Oracle Database Releases with Grid Infrastructure](using-earlier-oracle-database-releases-with-grid-infrastructure.md)
  Review the guidelines and restrictions for using earlier Oracle Database releases with Oracle Grid Infrastructure 19c installations.
- [Modifying Oracle Clusterware Binaries After Installation](modifying-oracle-clusterware-binaries-after-installation.md)
  After installation, if you must modify the software installed in your Grid home, then you must first stop the Oracle Clusterware stack.
