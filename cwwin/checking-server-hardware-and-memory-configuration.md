## Checking Server Hardware and Memory Configuration

Perform these tasks to gather your current system information.

- [Checking the Available RAM on Windows Systems](checking-the-available-ram-on-windows-systems.md)
  Use the control panel to check the available RAM on each server.
- [Checking the Currently Configured Virtual Memory on Windows Systems](checking-the-currently-configured-virtual-memory-on-windows-systems.md)
  Virtual memory (also known as a paging file) stores information that cannot fit in RAM, the main memory for the computer. All processes share the paging files, and a lack of space in the paging files can prevent processes from allocating memory.
- [Checking the System Processor Type](checking-the-system-processor-type.md)
  To view your processor type (32-bit or 64-bit), perform these steps.
- [Checking the Available Disk Space for Oracle Home Directories](checking-the-available-disk-space-for-oracle-home-directories.md)
  Additional shared disk space on a cluster file system is required for the Oracle Grid Infrastructure Management Repository (GIMR), Oracle Cluster Registry (OCR) and voting files used by Oracle Clusterware.
- [Checking the Available TEMP Disk Space](checking-the-available-temp-disk-space.md)
  The amount of disk space available in the TEMP directory is equivalent to the total amount of free disk space, minus what is needed to install the Oracle software.
