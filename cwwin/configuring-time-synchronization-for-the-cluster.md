## Configuring Time Synchronization for the Cluster

Oracle Clusterware requires the same time zone setting on all cluster nodes.

- [About Cluster Time Synchronization](about-cluster-time-synchronization.md)
  For the Microsoft Windows operating system, there are three different methods you can use to synchronize the time between the nodes of your cluster.
- [Understanding Network Time Requirements](understanding-network-time-requirements.md)
  Oracle Clusterware 19c is automatically configured with Cluster Time Synchronization Service (CTSS).
- [Configuring the Windows Time Service](configuring-the-windows-time-service.md)
  The Windows Time service (W32Time) provides network clock synchronization on computers running Microsoft Windows.
- [Configuring Network Time Protocol](configuring-network-time-protocol.md)
  The Network Time Protocol (NTP) is a client/server application.
- [Configuring Cluster Time Synchronization Service](configuring-cluster-time-synchronization-service.md)
  Cluster Time Synchronization Service (CTSS) is provided by Oracle to synchronize the time across the nodes in your cluster.
