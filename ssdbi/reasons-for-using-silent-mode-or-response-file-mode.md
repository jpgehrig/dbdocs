Review this section for use cases for running the installer in silent mode or response file mode.

| Mode          | Uses                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:--------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Silent        | Use silent mode for the following installations:<br>• Complete an unattended installation, which you schedule using operating system utilities such as `at`.<br>• Complete several similar installations on multiple systems without user interaction.<br>• Install the software on a system that does not have X Window System software installed on it.<br>The installer displays progress information on the terminal that you used to start it, but it does not display any of the installer screens. |
| Response file | Use response file mode to complete similar Oracle software installations on more than one system, providing default answers to some, but not all of the installer prompts.                                                                                                                                                                                                                                                                                                                                |
