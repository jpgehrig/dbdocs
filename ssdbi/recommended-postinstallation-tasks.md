Oracle recommends that you complete these tasks after installation.

- [Creating a Backup of the root.sh Script](creating-a-backup-of-the-root-sh-script.md)
  Oracle recommends that you back up the `root.sh` script after you complete an installation.
- [Setting Language and Locale Preferences for Client Connections](setting-language-preferences-for-client-connections.md)
  Configure client applications connecting to an Oracle Database according to your locale preferences and your I/O device character set.
- [Recompile Invalid Objects in the Database](recompiling-all-invalid-objects.md)
  After you install, patch, or upgrade a database, recompile invalid objects on the CDB and PDBs with a recompilation driver script.
- [About Installing Oracle Autonomous Health Framework](downloading-and-installing-the-orachk-health-check-tool.md)
  Install the latest version of Oracle Autonomous Health Framework to perform proactive heath checks and collect diagnostics data for the Oracle software stack.
- [Enabling Data Analytics Accelerators on SPARC for Oracle Database](enabling-data-analytics-accelerators-on-sparc-for-oracle-database.md)
  The microprocessors for the SPARC M7 and T7 series servers include Data Analytics Accelerator (DAX) coprocessors. These coprocessors perform query-related operations directly through the hardware, which improves Oracle Database performance.
