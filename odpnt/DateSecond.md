This property gets the `second` component of an `OracleDate.`

### Declaration

    // C#
    public int Second {get;}

### Property Value

A number that represents `Second`. Range of `Second` is (0 to 59).

### Exceptions

`OracleNullValueException` - `OracleDate` has a null value.
