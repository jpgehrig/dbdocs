This property specifies the day component of an `OracleTimeStamp.`

### Declaration

    // C#
    public int Day{get;}

### Property Value

A number that represents the day. Range of `Day` is (1 to 31).

### Exceptions

`OracleNullValueException` - The current instance has a null value.
