`OracleCredential` properties are listed in Table 6-60.

Table 6-60 OracleCredential Properties

| Property         | Description                                                                                                                                       |
|:-----------------|:--------------------------------------------------------------------------------------------------------------------------------------------------|
| `DBAPrivilege`   | Returns the DBA Privilege used to create the `OracleCredential` object. `OracleDBAPrivilege.None` is returned if it was not provided by the user. |
| `Password`       | Returns the password of the `OracleCredential` object.                                                                                            |
| `ProxyPassword ` | Returns the proxy user password of the `OracleCredential` object.                                                                                 |
| `ProxyUserId`    | Returns the proxy user id of the `OracleCredential` object.                                                                                       |
| `UserId`         | Returns the user id of the `OracleCredential` object.                                                                                             |
