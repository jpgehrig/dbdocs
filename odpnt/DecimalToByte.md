This method returns the `byte` representation of the current instance.

### Declaration

    // C#
    public byte ToByte();

### Return Value

A `byte`.

### Exceptions

`OverFlowException` - The `byte` cannot represent the current instance.

`OracleNullValueException` - The current instance has a null value.
