`Rollback` rolls back a database transaction.

### Overload List:

- [Rollback()](TransactionRollback1.md)

  This method rolls back a database transaction.

- [Rollback(string)](TransactionRollback2.md)

  This method rolls back a database transaction to a [savepoint](glossary.md) within the current transaction.
