This property gets the `month` component of an `OracleDate.`

### Declaration

    // C#
    public int Month {get;}

### Property Value

A number that represents `Month`. Range of `Month` is (1 to 12).

### Exceptions

`OracleNullValueException` - `OracleDate` has a null value.
