This property gets the year component of an `OracleTimeStamp.`

### Declaration

    // C#
    public int Year{get;}

### Property Value

A number that represents a year. The range of `Year` is (-4712 to 9999).

### Exceptions

`OracleNullValueException` - The current instance has a null value.
