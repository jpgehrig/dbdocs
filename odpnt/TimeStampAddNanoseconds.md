This method adds the supplied number of nanoseconds to the current instance.

### Declaration

    // C#
    public OracleTimeStamp AddNanoseconds(long nanoseconds);

### Parameters

- `nanoseconds`

  The supplied number of nanoseconds.

### Return Value

An `OracleTimeStamp`.

### Exceptions
