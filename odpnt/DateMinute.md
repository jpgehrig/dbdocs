This property gets the minute component of an `OracleDate`.

### Declaration

    // C#
    public int Minute {get;}

### Property Value

A number that represents `Minute`. Range of `Minute` is (0 to 59).

### Exceptions

`OracleNullValueException` - `OracleDate` has a null value.
