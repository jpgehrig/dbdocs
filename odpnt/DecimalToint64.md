This method returns the `Int64` representation of the current instance.

### Declaration

    // C#
    public long ToInt64();

### Return Value

A `long`.

### Exceptions

`OverFlowException` - The `long` cannot represent the current instance.

`OracleNullValueException` - The current instance has a null value.
