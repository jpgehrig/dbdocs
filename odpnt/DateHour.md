This property gets the `hour` component of an `OracleDate`.

### Declaration

    // C#
    public int Hour {get;}

### Property Value

A number that represents `Hour`. Range of `Hour` is (0 to 23).

### Exceptions

`OracleNullValueException` - `OracleDate` has a null value.
