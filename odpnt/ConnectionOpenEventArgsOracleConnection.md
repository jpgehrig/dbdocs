This property specifies the `OracleConnection` on which connection open event has occurred.

### Declaration

    // C#
    public Connection{ get;}

### Property Value

Returns a `OracleConnection` object on which `Open()` is called.    

### Remarks

Only supported for .NET Framework 4 and higher.
