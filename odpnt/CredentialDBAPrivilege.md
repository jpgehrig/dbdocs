This property returns the DBA Privilege that is associated with the user.

### Declaration

    // C#
    OracleDBAPrivilege DBAPrivilege { get; }

### Property Value

The `OracleDBAPrivilege` enum value that is associated with the user.

### Remarks

`OracleDBAPrivilege.None` is returned if it was not set by the user.
