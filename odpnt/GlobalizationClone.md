This method creates a copy of an `OracleGlobalization` object.

### Declaration

    // C#
    public object Clone();

### Return Value

An `OracleGlobalization` object.

### Implements

`ICloneable`

### Remarks

The cloned object has the same property values as that of the object being cloned.
