This static field represents the minimum value for an `OracleIntervalDS` structure.

### Declaration

    // C#
    public static readonly OracleIntervalDS MinValue;

### Remarks

Minimum values:

- Day: -999999999

- hour: -23

- minute: -59

- second: -59

- nanosecond: -999999999
