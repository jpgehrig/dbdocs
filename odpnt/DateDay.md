This property gets the day component of an `OracleDate`.

### Declaration

    // C#
    public int Day{get;}

### Property Value

A number that represents the day. Range of `Day` is (1 to 31).

### Exceptions

`OracleNullValueException` - `OracleDate` has a null value.
