The Oracle providers for ASP.NET reside in namespaces contained in one assembly: `Oracle.Web.dll`.

Table 1-1 lists the provider types, class names, and namespaces that are part of `Oracle.Web.dll`.

Table 1-1 Oracle Providers for ASP.NET Namespaces and Providers

| Provider Type    | Class Name                                                                   | Namespace                    |
|:-----------------|:-----------------------------------------------------------------------------|:-----------------------------|
| Membership       | [OracleMembershipProvider Class](OracleMembershipProviderClass.md)           | `Oracle.Web.Security`        |
| Role             | [OracleRoleProvider Class](OracleRoleProviderClass.md)                       | `Oracle.Web.Security`        |
| Site Map         | [OracleSiteMapProvider Class](OracleSiteMapProviderClass.md)                 | `Oracle.Web.SiteMap`         |
| Session State    | [OracleSessionStateStore Class](OracleSessionStateStoreClass.md)             | `Oracle.Web.SessionState`    |
| Profile          | [OracleProfileProvider Class](OracleProfileProviderClass.md)                 | `Oracle.Web.Profile`         |
| Web Event        | [OracleWebEventProvider Class](OracleWebEventProviderClass.md)               | `Oracle.Web.Management`      |
| Personalization  | [OraclePersonalizationProvider Class](OraclePersonalizationProviderClass.md) | `Oracle.Web.Personalization` |
| Cache Dependency | [OracleCacheDependency Class](OracleCacheDependencyClass.md)                 | `Oracle.Web.Caching`         |
