Oracle Database Client installation software is available in multiple media, and can be installed using several options.

The Oracle Database Client software is available on installation media, or you can download it from the Oracle Technology Network website, or the Oracle Software Delivery Cloud portal. In most cases, you use the graphical user interface (GUI) provided by Oracle Universal Installer (OUI) to install the software. However, you can also use Oracle Universal Installer to complete silent mode installations, without using the GUI.

**Note:**

You cannot use Oracle Universal Installer from an earlier Oracle release to install components from this release.
