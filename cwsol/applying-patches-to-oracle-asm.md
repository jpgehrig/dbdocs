After you have upgraded Oracle Grid Infrastructure 19c, you can install individual software patches by downloading them from My Oracle Support.

- [About Individual Oracle Grid Infrastructure Patches](about-individual-one-off-oracle-asm-patches.md)
  Download Oracle ASM individual (one-off) patch and apply it to Oracle Grid Infrastructure using the OPatch Utility.
- [About Oracle Grid Infrastructure Software Patch Levels](about-oracle-asm-software-patch-levels.md)
  Review this topic to understand how to apply patches for Oracle ASM and Oracle Clusterware.
- [Patching Oracle Grid Infrastructure](patching-oracle-grid-infrastructure.md)
  Review these topics to patch Oracle Grid Infrastructure in different stages of installation or upgrade.
- [Patching and Switching Oracle Grid Infrastructure Homes](switching-oracle-grid-infrastructure-home-after-patching.md)
  Use `switchGridHome` command to switch from the current Oracle Grid Infrastructure home to the patched Oracle Grid Infrastructure home.
