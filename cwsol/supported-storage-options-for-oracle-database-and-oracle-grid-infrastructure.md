  During Oracle Grid Infrastructure installation, you have the option of configuring Oracle ASM on a Network File System.
- [Using Logical Volume Managers with Oracle Grid Infrastructure and Oracle RAC](using-logical-volume-managers-with-oracle-grid-infrastructure-and-oracle-rac.md)
  Oracle Grid Infrastructure and Oracle RAC only support cluster-aware volume managers.
- [About NFS Storage for Data Files](about-nfs-storage-for-data-files.md)
  Review this section for NFS storage configuration guidelines.
- [About Direct NFS Client Mounts to NFS Storage Devices](about-direct-nfs-client-mounts-to-nfs-storage-devices.md)
