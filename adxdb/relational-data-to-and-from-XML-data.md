There are various ways that you can view existing relational data as XML data.

- [Generation of XML Data from Relational Data](generation-of-XML-data-from-relational-data.md)
  Oracle XML DB provides features for generating (constructing) XML data from relational data in the database. There are both SQL/XML standard functions and Oracle-specific functions and packages for generating XML data from relational content.
- [Relational Views over XML Data](relational-views-over-XML-data.md)
  Relational database views over XML data provide conventional, relational access to XML content.
- [XMLType Views](XMLType-views.md)
  You can create `XMLType` views over relational and object-relational data.
