**Packages**

| Package                                                                                 | Description                                                                                                                                                 |
|-----------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [oracle.i18n.lcsd](oracle/i18n/lcsd/package-summary.md)                                 | Provides classes to automatically detect and recognize language, encoding, or both based on text input.                                                     |
| [oracle.i18n.net](oracle/i18n/net/package-summary.md)                                   | Provides internet-related data conversions for globalization.                                                                                               |
| [oracle.i18n.servlet](oracle/i18n/servlet/package-summary.md)                           | Supports JSP / Java Servlet globalization by automatically detecting the current locale and providing facilities to retrieve appropriate localized content. |
| [oracle.i18n.servlet.filter](oracle/i18n/servlet/filter/package-summary.md)             | Provides the Java Servlet filters that detect the current user locale.                                                                                      |
| [oracle.i18n.servlet.listener](oracle/i18n/servlet/listener/package-summary.md)         | Provides default listener classes used for JSP / Java Servlet applications.                                                                                 |
| [oracle.i18n.servlet.localesource](oracle/i18n/servlet/localesource/package-summary.md) | Provides classes that are plug-ins for automatic locale detectors.                                                                                          |
| [oracle.i18n.text](oracle/i18n/text/package-summary.md)                                 | Provides general text data globalization support, such as collation, date/time format, and number/currency format, associated with specific Oracle locale.  |
| [oracle.i18n.util](oracle/i18n/util/package-summary.md)                                 | Provides general utilities for globalization support.                                                                                                       |

This document is the API specification for the Oracle Database Globalization Development Kit. The Oracle Database Globalization Development Kit provides compatible globalization functionality that is incorporated in Oracle database servers. The Oracle Database Globalization Development Kit also provides the globalization framework that simplifies the development of middle-tier applications.
