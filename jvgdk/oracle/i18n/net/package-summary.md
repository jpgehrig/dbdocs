# Package oracle.i18n.net

Provides internet-related data conversions for globalization.

See: Description

- **Class Summary**

  | Class                                                   | Description                                                                                                                               |
  |---------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------|
  | [CharEntityReference](CharEntityReference.md)           | The `CharEntityReference` class is a utility class to escape or unescape a string into a character reference or an entity reference form. |
  | [CharEntityReference.Form](CharEntityReference.Form.md) | Form parameter class that specifies the escaped form.                                                                                     |
  | [MimeUtility](MimeUtility.md)                           | The `MimeUtility` contains encoder and decoder information for MIME header and body text.                                                 |
  | [URLDecoder](URLDecoder.md)                             | The `URLDecoder` contains a utility method for converting from a MIME format called `x-www-form-urlencoded` to a `String` object.         |
  | [URLEncoder](URLEncoder.md)                             | The `URLEncoder` contains a utility method for converting a `String` object into a MIME format called `x-www-form-urlencoded` format.     |
