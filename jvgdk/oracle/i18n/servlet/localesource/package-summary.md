# Package oracle.i18n.servlet.localesource

Provides classes that are plug-ins for automatic locale detectors.

See: Description

- **Class Summary**

  | Class                                                             | Description                                                                                                                                  |
  |-------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------|
  | [ApplicationDefault](ApplicationDefault.md)                       | The `ApplicationDefault` class is the default locale source class that represents the default locale and attributes used in the application. |
  | [DBLocaleSource](DBLocaleSource.md)                               | The `DBLocaleSource` class is the predefined database locale source that accesses a user profile table including user locale preferences.    |
  | [HttpAcceptLanguage](HttpAcceptLanguage.md)                       | The `HttpAcceptLanguage` class is a locale source class that carries the language preference of the web client.                              |
  | [LocaleSource](LocaleSource.md)                                   | The `LocaleSource` class is the abstract base class for locale source objects.                                                               |
  | [LocaleSource.Alignment](LocaleSource.Alignment.md)               | The `LocaleSource.Alignment` class represents the alignment of text elements.                                                                |
  | [LocaleSource.Parameter](LocaleSource.Parameter.md)               | The `LocaleSource.Parameter` class represents locale and attribute variable names.                                                           |
  | [LocaleSource.WritingDirection](LocaleSource.WritingDirection.md) | The `LocaleSource.WritingDirection` class represents the writing direction of the locale.                                                    |
  | [UserInput](UserInput.md)                                         | The `UserInput` class calls the `request.getParameter(LocaleSource.Parameter)` method to retrieve the user input.                            |

## Package oracle.i18n.servlet.localesource Description

Provides classes that are plug-ins for automatic locale detectors.
