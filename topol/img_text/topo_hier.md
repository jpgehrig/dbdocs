# Description of the illustration topo_hier.eps

This figure illustrates a topology hierarchy with five levels, as explained in text before the illustration. The Land Parcels topology geometry layer (level 0) is the lowest level of the hierarchy. Its parent is the Block Groups layer (level 1), whose parent is the Tracts layer (level 2), whose parent is the Counties layer (level 3), whose parent is the States layer (level 4).
