Table 13-2 defines the common constants used by all OCCI classes. Constants that are defined for use within specific classes are summarized at the beginning of class-specific sections.

Table 13-2 Enumerated Values Used by All OCCI Classes

| Attribute      | Options                                                                                                                                                                                                                                                                                                                                                |
|:---------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `LockOptions`  | • `OCCI_LOCK_NONE` clears the lock setting on the `Ref` object.<br>• `OCCI_LOCK_X` indicates that the object should be locked, and to wait for the lock to be available if the object is locked by another session.<br>• `OCCI_LOCK_X_NOWAIT` indicates that the object should be locked, and returns an error if it is locked by another session.     |
| `CharSetForm`  | • `OCCI_SQLCS_IMPLICIT` indicates that the local database character set must be used.<br>• `OCCI_SQLCS_NCHAR` indicates that the local database `NCHAR` set must be used.<br>• `OCCI_SQLCS_EXPLICIT` indicates that the character set is specified explicitly.<br>• `OCCI_SQLCS_FLEXIBLE` means that the character set is a PL/SQL flexible parameter. |
| `ReturnStatus` | • `OCCI_SUCCESS` indicates that the call has been made successfully (transaction failover mode).<br>• `FO_RETRY` indicates that the call should be retried (transaction failover mode).                                                                                                                                                                |
