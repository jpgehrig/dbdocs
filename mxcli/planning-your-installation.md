The Oracle Database installation process consists of the following phases:

1.  Review the licensing information: Although the installation media in your media pack contain many Oracle components, you are permitted to use only those components for which you have purchased licenses.
    Oracle Support Services does not provide support for components for which licenses have not been purchased.

    **See Also:**

    [Oracle Database Licensing Information](../dblic/Licensing-Information.md)
2.  Plan the installation: This chapter describes the Oracle products that you can install and issues that you must consider before starting the installation.
3.  Complete preinstallation tasks: [Oracle Database Instant Client Preinstallation Tasks](oracle-database-client-preinstallation-tasks.md) describes preinstallation tasks that you must complete before installing the product.
4.  Install the software: [Installing and Removing Oracle Database Instant Client](installing-and-removing-oracle-database-client.md) describes how to install Oracle Database Instant Client.
5.  Complete postinstallation tasks: [Oracle Database Instant Client Postinstallation Tasks](oracle-database-client-postinstallation-tasks.md) describes recommended and required postinstallation tasks.

**Parent topic:** [Overview of Oracle Database Instant Client Installation](overview-of-oracle-database-client-installation.md)
