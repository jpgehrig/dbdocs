# Description of the illustration access_control.gif

Graphic shows the three dimensions of Data Security. At the center is a box labeled ‘Access Control List (ACL)’ containing a statement ‘Grant modifyProject to ProjectManager on Team A’s Projects’. To the left of the center box is a box labeled ‘Provilege (P):’ with a privilege named ‘modifyProject’. To the right of the center box is a box labeled ‘User/Role’ with a user named ‘ProjectManager’. Below the center box is a box labeled ‘Data Realm (R): with a data realm named ‘Team A’s Projects’.
