## 11  Oracle Database Real Application Security PL/SQL Packages

This chapter describes the PL/SQL packages that are available with Oracle Database Real Application Security.

Table 11-1 lists these packages. Detailed information on each package follows this table.

Table 11-1 Oracle Database Real Application Security PL/SQL Packages

| PL/SQL Package                                                    | Description                                                                                                                                                  |
|:------------------------------------------------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| [DBMS_XS_SESSIONS Package](DBMS_XS_SESSION-package.md)            | Includes subprograms to manage an application session.                                                                                                       |
| [XS_ACL Package](XS_ACL-package.md)                               | Includes subprograms to create, manage, and delete Access Control Lists (ACLs) and to add and remove parameter values.                                       |
| [XS_ADMIN_UTIL Package](XS_ADMIN_UTIL-package.md)                 | Includes helper subprograms.                                                                                                                                 |
| [XS_DATA_SECURITY Package](XS_DATA_SECURITY-package.md)           | Includes subprograms to create, manage, and delete data security policies, associated data realm constraints, column constraints, and ACL parameters.        |
| [XS_DATA_SECURITY_UTIL Package](XS_DATA_SECURITY_UTIL-package.md) | Includes subprograms to schedule automatic refreshment for static ACL to a user table and change the ACL refreshment mode to on-commit or on-demand refresh. |
| [XS_DIAG Package](XS_DIAG-package.md)                             | Includes subprograms to diagnose potential problems in Real Application Security objects and report identified inconsistencies.                              |
| [XS_NAMESPACE Package](XS_NAMESPACE-package.md)                   | Includes subprograms to create, manage, and delete namespace templates and attributes.                                                                       |
| [XS_PRINCIPAL Package](XS_PRINCIPAL-package.md)                   | Includes subprograms to create, manage, and delete application users and roles.                                                                              |
| [XS_SECURITY_CLASS Package](XS_SECURITY_CLASS-package.md)         | Includes subprograms to create, manage, and delete security classes and their privileges. Also includes subprograms for managing security class inheritance. |
