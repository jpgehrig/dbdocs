# Oracle Database JDBC Java API Reference

**Packages**

| Package                                                             | Description                                                                                                                                               |
|---------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| [oracle.jdbc](oracle/jdbc/package-summary.md)                       | Beginning in Oracle9*i*, the Oracle extensions to JDBC are captured in the package `oracle.jdbc`.                                                         |
| [oracle.jdbc.aq](oracle/jdbc/aq/package-summary.md)                 | This package is an Oracle JDBC extension that provides interfaces to access the Advanced Queuing feature of Oracle for enterprise messaging applications. |
| [oracle.jdbc.babelfish](oracle/jdbc/babelfish/package-summary.md)   | Provides the classes necessary for the support for application migration feature.                                                                         |
| [oracle.jdbc.datasource](oracle/jdbc/datasource/package-summary.md) | Beginning in Oracle Release 12.2, some of the Oracle extensions to JDBC are captured in the package `oracle.jdbc.datasource`.                             |
| [oracle.jdbc.dcn](oracle/jdbc/dcn/package-summary.md)               | This package is an Oracle JDBC extension that provides interfaces to access the Database Change Notification feature of Oracle.                           |
| [oracle.jdbc.pool](oracle/jdbc/pool/package-summary.md)             | A package of connection cache and pooling related classes.                                                                                                |
| [oracle.jdbc.replay](oracle/jdbc/replay/package-summary.md)         | Provides interfaces and factory methods for Application Continuity.                                                                                       |
| [oracle.jdbc.xa](oracle/jdbc/xa/package-summary.md)                 | Provides classes that implement the JDBC XA APIs.                                                                                                         |
| [oracle.jdbc.xa.client](oracle/jdbc/xa/client/package-summary.md)   | Provides classes that implement the JDBC XA APIs.                                                                                                         |
| [oracle.sql](oracle/sql/package-summary.md)                         | A package of classes that represent java SQL types and Oracle specific SQL types.                                                                         |
