Learn how to upgrade Oracle Restart to a later release using the out-of-place upgrade mode and install the patches.

- [Steps to Upgrade Oracle Restart](upgrading-oracle-restart.md)
  Complete this procedure to upgrade Oracle Grid Infrastructure for a standalone server (Oracle Restart) from an earlier release.
- [Verifying the Oracle Restart Software Version After Upgrade](verifying-oracle-restart-software-version-after-upgrade.md)
  Check the software release version of Oracle Restart after the upgrade.
- [Downloading Release Update Patches](downloading-and-installing-patches.md)
  Download and install Release Updates (RU) and Monthly Recommended Patches (MRPs) patches for your Oracle software after you complete installation.
- [Patching Oracle Restart](patching-oracle-restart.md)
  After you have upgraded to Oracle Grid Infrastructure for a standalone server (Oracle Restart) 19c, you can install individual software patches by downloading them from My Oracle Support.
- [Patching and Switching Oracle Grid Infrastructure Homes](switch-gi-home-patching.md)
  Perform an out-of-place Oracle Restart patching by switching from the current Oracle Grid Infrastructure home to a patched Oracle Grid Infrastructure home.
- [Unlocking and Deinstalling the Previous Release Grid Home](unlocking-and-deinstalling-the-previous-release-grid-home.md)
  After upgrading from previous releases, if you want to deinstall the previous release Grid home, then you must first change the permission and ownership of the previous release Grid home.
