# Package oracle.express.spl

Contains classes that support the execution of OLAP DML commands in Oracle OLAP.

See: Description

- **Class Summary**

  | Class                         | Description                                                                                         |
  |-------------------------------|-----------------------------------------------------------------------------------------------------|
  | [SPLExecutor](SPLExecutor.md) | An object that accepts a `String` and sends it to Oracle OLAP for internal execution or evaluation. |

- **Exception Summary**

  | Exception                               | Description                                                                                                         |
