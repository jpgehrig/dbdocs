# Package oracle.express

Contains classes that support processing in Oracle OLAP.

See: Description

- **Class Summary**

  | Class                                   | Description                                                                                                                 |
  |-----------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
  | [ErrorDescription](ErrorDescription.md) | A description of an error that caused an OLAP API method to throw an exception that is related to execution in Oracle OLAP. |
  | [ErrorStack](ErrorStack.md)             | An object that provides information about an exception that is related to Oracle OLAP execution.                            |

- **Exception Summary**

  | Exception                                               | Description                                                                                                                                                                                                                         |
  |---------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
  | [ExpressServerException](ExpressServerException.md)     | Indicates that the internal Oracle OLAP code cannot fulfill a request that was made by the OLAP API client code.                                                                                                                    |
  | [ObjectClosedException](ObjectClosedException.md)       | Indicates that you have called an OLAP API method that requires retrieval of information from Oracle OLAP, and that communication is not possible because the resources required for the communication have been freed.             |
  | [TaskInterruptedException](TaskInterruptedException.md) | Indicates that the connection to the Oracle Database has been interrupted by Oracle OLAP.                                                                                                                                           |
  | [UnexpectedException](UnexpectedException.md)           | Indicates that you have called a method that requires the internal OLAP API client code to request information from Oracle OLAP, and the results that were returned do not conform to the expectations of the OLAP API client code. |

## Package oracle.express Description

Contains classes that support processing in Oracle OLAP.
