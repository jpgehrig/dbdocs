      public class TransactionTypeUnavailableException
      extends OLAPIRuntimeException

  Indicates that the type of the `Transaction` requested is not available. For example, if an application tries to create a `Cursor` while in a write `Transaction`, then the `TransactionProvider` throws this exception.
