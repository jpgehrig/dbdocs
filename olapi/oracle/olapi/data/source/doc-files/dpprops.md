**DataProvider Settings**

The following table lists the keys and the case-sensitive values for the settings that you can specify in a `Properties` object or XML string for a `DataProvider` or a `UserSession` and provides a brief description of them.

| Properties Key or<br>Setting Name | Value                                         | Property Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|-----------------------------------|-----------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `HierarchyValueType`              | `unique`<br>`local`                           | Specifies whether to use unique or local values for members of dimension hierarchies. The use of `Model` objects requires unique dimension hierarchy values. For more information on unique and local values, see the Overview of this documentation.<br>The `unique` value specifies using a three part value that identifies the dimension hierarchy, the level in the hierarchy, and the local value of the dimension member in the level. It is the default value for the setting.<br>The `local` value specifies using only the local dimension member value.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `MetadataReaderMode`              | `ALL`<br>`11_ONLY`<br>`10103AWONLY`<br>`NONE` | Specifies the type of metadata recognized by the `MdmMetadataProvider` provided by the `DataProvider`.<br>The `ALL` value specifies that the `MdmMetadataProvider` recognizes all types of Oracle OLAP metadata objects. It is the default value for the setting.<br>The `11_ONLY` value specifies that the `MdmMetadataProvider` recognizes only Oracle OLAP 11*g* metadata model objects.<br>The `10103AWONLY` value specifies that the `MdmMetadataProvider` recognizes only 10*g* standard form analytic workspace metadata. This metadata is generated for an analytic workspace by the Oracle OLAP Analytic Workspace Java API and by Analytic Workspace Manager in Oracle Database 10*g* releases. Oracle OLAP first used this type of metadata in Oracle Database 10*g* Release 1 (10.1.0.3).<br>The `NONE` value specifies that the `MdmMetadataProvider` does not recognize any pre-existing metadata objects. The `MdmMetadataProvider` recognizes only the metadata objects that an application creates in the current session.                                                                                                                                                                                                                                                                                             |
| `SupportMTM`                      | `NO`<br>`YES`                                 | Specifies whether Oracle OLAP supports the mapping of metadata objects to source data by the use of the classes in the `oracle.olapi.metadata.mapping` package or by the use of the deprecated classes in the `oracle.olapi.metadata.mtm` package.<br>The `NO` value specifies that Oracle OLAP supports the mapping of metadata objects to source data by the classes in the `oracle.olapi.metadata.mapping` package. It is the default value of the setting.<br>The `NO` value is required for the `ALL` and the `11_ONLY` metadadata reader modes. In those modes an application can create permanent metadata objects and map them to data sources. For the other metadata reader modes, a `NO` value specifies that Oracle OLAP uses the `oracle.olapi.metadata.mapping` classes to map metadata objects to source data.<br>The `YES` value specifies that the Oracle OLAP supports the mapping of metadata objects to source data by the deprecated classes in the `oracle.olapi.metadata.mtm` package. This setting provides backward compatibility for applications that use `mtm` package classes. An application can create transient metadata objects and map them using `mtm` classes.<br>As of 11*g* Release 2 (11.2), *Oracle OLAP Java API Reference* no longer contains documentation for the deprecated `mtm` classes. |
