## Package oracle.olapi.resource Description

Provides support for the internationalization of messages for `Exception` classes in the Oracle OLAP Java API. The classes in this package extend the java.util.ListResourceBundle class. For information on that class, see [ListResourceBundle](http://docs.oracle.com/javase/6/docs/api/java/util/ListResourceBundle.html).
