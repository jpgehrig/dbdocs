      public final class StarArgument
      extends DataObject
      implements FunctionArgument

  A `DataObject` that represents a `*` (asterisk) argument. A `StarArgument` is similiar to a `*` in the select list of a SQL `SELECT` statement. An application gets an instance of this class by using the `INSTANCE` constant.
