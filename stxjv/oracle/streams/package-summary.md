# Package oracle.streams

- **Interface Summary**

  | Interface                                                 | Description                                                                                                                                                                                                 |
  |-----------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
  | [ChunkColumnValue](ChunkColumnValue.md)                   | The ChunkColumnValue interface encapsulates the information about a LOB, LONG, or XMLTYPE column in a RowLCR.                                                                                               |
  | [ColumnValue](ColumnValue.md)                             | The ColumnValue interface encapsulates the information about a column in a RowLCR.                                                                                                                          |
  | [DDLLCR](DDLLCR.md)                                       | The DDLLCR interface encapsulates the information about a DDL LCR.                                                                                                                                          |
  | [LCR](LCR.md)                                             | The LCR interface encapsulates information about the logical change record (LCR).                                                                                                                           |
  | [RowLCR](RowLCR.md)                                       | The RowLCR interface encapsulates the information about a row logical change record (LCR).                                                                                                                  |
  | [XStreamLCRCallbackHandler](XStreamLCRCallbackHandler.md) | The XStreamLCRCallbackHandler interface enables clients to receive LCRs and chunk data from an XStream outbound server or send LCRs and chunk data to an XStream inbound server using a callback mechanism. |

- **Class Summary**

  | Class                                                 | Description                                                                                                    |
  |-------------------------------------------------------|----------------------------------------------------------------------------------------------------------------|
  | [AbstractLCR](AbstractLCR.md)                         | The AbstractLCR class provides an abstract implementation of the LCR interface.                                |
  | [DefaultChunkColumnValue](DefaultChunkColumnValue.md) | The DefaultChunkColumnValue class provides an Oracle default implementation of the ChunkColumnValue interface. |
  | [DefaultColumnValue](DefaultColumnValue.md)           | The DefaultColumnValue class provides an Oracle default implementation of ColumnValue interface.               |
  | [DefaultDDLLCR](DefaultDDLLCR.md)                     | The DefaultDDLLCR class provides an Oracle default implementation of the DDLLCR interface.                     |
  | [DefaultRowLCR](DefaultRowLCR.md)                     | The DefaultRowLCR class provides an Oracle default implementation of the RowLCR interface.                     |
  | [XStreamIn](XStreamIn.md)                             | The XStreamIn class provides APIs for using Oracle XStream In.                                                 |
  | [XStreamOut](XStreamOut.md)                           | The XStreamOut class provides APIs for using Oracle XStream Out.                                               |
  | [XStreamUtility](XStreamUtility.md)                   | The XStreamUtility class provides utility methods for using XStream APIs.                                      |
