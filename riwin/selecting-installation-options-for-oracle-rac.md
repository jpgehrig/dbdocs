## Selecting Installation Options for Oracle RAC

Review the topics to select options for installing Oracle RAC.

- [Selecting a Security Notification Contact](selecting-a-security-notification-contact.md)
  During installation, you are asked in the Configure Security Updates screen to provide a security contact.
- [Selecting an Installation Option](selecting-an-installation-option.md)
  You must choose one of the installation options for installing the software.
- [Selecting the Database Type for Oracle Grid Infrastructure Deployments](selecting-the-database-type-for-oracle-grid-deployments.md)
  During installation, Oracle Universal Installer (OUI) detects if you have Oracle Grid Infrastructure for a cluster installed. If you do, then you must specify the type of database you plan to create.
- [Choosing the Cluster Database Management Type](choosing-the-cluster-database-management-type.md)
  When creating an Oracle RAC database, you can choose one of two types of databases to create.
- [Selecting an Installation Type](selecting-an-installation-type.md)
  When you run Oracle Universal Installer (OUI) to install Oracle RAC, you can select the Typical or the Advanced installation type.
- [Selecting a Database Name](selecting-a-database-name.md)
  The database name is comprised of various strings and must contain only permitted characters. Review the following guidelines when selecting a database name.
- [Requirements for Database Passwords](requirements-for-database-passwords.md)
  To secure your database, use passwords that satisfy the Oracle recommended password requirements, even the passwords for predefined user accounts.
- [About Automatic Memory Management Installation Options](about-automatic-memory-management-installation-options.md)
  Decide if you want to configure Automatic Memory Management during installation.
- [About Character Set Selection During Installation](about-character-set-selection-during-installation.md)
  Before you create the database, decide the character set that you want to use.
- [Managing Database Services After Installation](managing-database-services-after-installation.md)
  Use the Server Control Utility (SRVCTL), or use Oracle Enterprise Manager Database Express, or Oracle Enterprise Manager Cloud Control for all administration and monitoring of database services for an Oracle RAC database.
