## Installing the Oracle Database Vault Option

Installing and configuring Oracle Database Vault requires actions during and after installation.

- [Starting the Listener with Oracle Database Vault Installations](starting-the-listener-with-oracle-database-vault-installations.md)
  You must start the listener and database instance on all Oracle RAC nodes other than the one on which the installation is performed.
- [Configuring Oracle Database Vault Using DBCA](configuring-oracle-database-vault-using-dbca.md)
  You can configure Oracle Database Vault after installation using Oracle Database Configuration Assistant (DBCA), or choose not to configure Oracle Database Vault.
- [Perform Postinstallation Configuration for Oracle Database Vault](perform-postinstallation-configuration-for-oracle-database-vault.md)
  After you install the Oracle Database Vault option, you can be required to make additional changes to your database.
