# Description of the illustration

This image shows the General tab page for a territory. It contains the following text fields and their contents: Territory Name (REDWOOD SHORES), Territory ID (1001), Territory Abbreviation (RS), Territory Variation (blank). The Show Existing Definitions button is at the bottom of the tab page. A toolbar is on the left side of the screen. The following menus appear at the top: File, Edit, Tools, Help.
