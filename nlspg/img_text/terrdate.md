# Description of the illustration

This image shows the Date & Time tab page. It contains the following combo boxes:

- Short Date Format

- Short Time Format

- Oracle Date Format

- Long Date Format

- Timestamp Time Zone Format

The contents of the combo boxes is described in the text following the image.

Each combo box is followed by an example. Between the Short Time Sample and the Oracle Date Format is a Combined Short Date & Time Sample.

A toolbar is on the left side of the screen. The following menus appear at the top: File, Edit, Tools, Help.
