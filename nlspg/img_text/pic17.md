# Description of the illustration

The second row of scrolling menus contains Territory Abbreviation, Chracter Set(ID), and Linguistic Sort(ID). Open and Close buttons appear in the lower right of the dialog box. Text at the bottom of the dialog box shows that the Corresponding File Name for AMERICAN(1) is lx00001.nlb.
