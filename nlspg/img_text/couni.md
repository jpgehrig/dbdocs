# Description of the illustration

This image shows the Unicode Collation Sequence tab page. A combo box shows the nodes in the collation. Most of the visible information shows a tertiary level with 10 nodes. Several of the characters in the nodes are variations of the number 4. The following node is highlighted: \x0034 4.

The following buttons are below the combo box:

- Add

- Modify

- Cut

- Paste (not available)

- Search

- FullView

A toolbar is on the left side of the screen. The following menus are at the top of the screen: File, Edit, Tools, Help.
