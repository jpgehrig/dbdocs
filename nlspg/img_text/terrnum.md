# Description of the illustration

This image shows the Number tab page. It contains, from top to bottom, the following items:

- Decimal Symbol combo box

- Negative Sign Location radio buttons (-100 and 100-)

- Numeric Group Separater combo box

- Number Grouping combo box

- Number Sample (using the settings)

- List Separator combo box

- Measurement System combo box

- Rounding Indicator combo box

- Rounding Sample (using the settings)

A toolbar is on the left side of the screen. The following menus appear at the top: File, Edit, Tools, Help.
