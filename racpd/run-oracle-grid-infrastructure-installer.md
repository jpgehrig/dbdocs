## Run the Oracle Grid Infrastructure Installer

To install Oracle Grid Infrastructure on the container, complete these procedures.

- [Extract the Oracle Grid Infrastructure Files](extract-oracle-grid-infrastructure-files.md)
  From your client connection to the Podman container as the `grid` user, download, extract Oracle Grid Infrastructure binaries, and the binary files to 19.16.
- [Start the Oracle Grid Infrastructure Installer](start-oracle-grid-infrastructure-installer-ha.md)
  Use this procedure to start up the Oracle Grid Infrastructure installer, and provide information for the configuration.
