## Install Oracle Grid Infrastructure and Oracle RAC

To set up Oracle Grid Infrastructure and Oracle Real Application Clusters (Oracle RAC) in Podman containers, complete these steps.

- [Set Up the Podman Containers for Oracle Grid Infrastructure Installation](set-podman-container-oracle-grid-infrastructure-installation.md)
  To prepare for Oracle Real Application Clusters (Oracle RAC), complete these steps on the Podman containers.
- [Configure Remote Display for Installation](configure-remote-display-installation.md)
  To use a remote display for Oracle Grid Infrastructure and Oracle Real Application Clusters (Oracle RAC) for installation, you must perform these configuration steps.
- [Run the Oracle Grid Infrastructure Installer](run-oracle-grid-infrastructure-installer.md)
  To install Oracle Grid Infrastructure on the container, complete these procedures.
- [Run the Oracle RAC Database Installer](run-oracle-rac-database-installer.md)
  To install Oracle Real Application Clusters (Oracle RAC), run the Oracle RAC installer.
- [Create the Oracle RAC Database with DBCA](create-oracle-rac-database-dbca.md)
  To create the Oracle Real Application Clusters (Oracle RAC) database on the container, complete these steps with Database Configuration Assistant (DBCA).
