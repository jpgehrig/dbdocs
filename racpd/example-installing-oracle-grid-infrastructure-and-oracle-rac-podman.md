To assist you with a successful deployment, Oracle strongly recommends that you review My Oracle Support Doc ID 2885873.1.

  The client machine used for remote based graphic user interface (GUI) installation of Oracle Real Application Clusters (Oracle RAC) into Podman containers used this configuration.

  To set up Oracle Grid Infrastructure and Oracle Real Application Clusters (Oracle RAC) in Podman containers, complete these steps.
