## 243  SDO_GEOR_UTL

The `SDO_GEOR_UTL` package contains utility functions and procedures for the Oracle Spatial GeoRaster feature, including those related to using triggers with GeoRaster data.

For complete description of this package within the context of Oracle Spatial, see [`SDO_GEOR_UTL`](../geors/SDO_GEOR_UTL-reference.md) in the Oracle Spatial and Graph GeoRaster Developer's Guide.
