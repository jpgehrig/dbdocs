## 260  SEM_PERF

The `SEM_PERF` package contains subprograms for examining and enhancing the performance of the Resource Description Framework (RDF) and Web Ontology Language (OWL) support in an Oracle database.

For a complete description of this package within the context of Oracle Database semantic technology support, see [`SEM_PERF`](../rdfrm/SEM_PERF-reference.md) in the Oracle Spatial and Graph RDF Semantic Graph Developer's Guide.
