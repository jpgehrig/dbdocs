## 258  SEM_APIS

The `SEM_APIS` package contains subprograms for working with the Resource Description Framework (RDF) and Web Ontology Language (OWL) in an Oracle database.

For a complete description of this package within the context of Oracle Database semantic technology support, see [`SEM_APIS`](../rdfrm/SEM_APIS-reference.md) in the Oracle Spatial and Graph RDF Semantic Graph Developer's Guide.
