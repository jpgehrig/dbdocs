## 241  SDO_GEOR_AGGR

The `SDO_GEOR_AGGR` package provides an interface to the SDO_GEOR_AGGR package for performing aggregate operations on GeoRaster objects.

For a complete description of this package within the context of Oracle Spatial, see [`SDO_GEOR_AGGR`](../geors/SDO_GEOR_AGGR-referencer-ref.md) in the Oracle Spatial and Graph GeoRaster Developer's Guide.
