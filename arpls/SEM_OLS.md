## 259  SEM_OLS

The `SEM_OLS` package provides an interface to the `SEM_OLS` package for providing triple-level security to RDF data, using Oracle Label Security (OLS).

For a complete description of this package, see [`SEM_OLS`](../rdfrm/SEM_OLS-reference.md) in the Oracle Spatial and Graph RDF Semantic Graph Developer's Guide.
