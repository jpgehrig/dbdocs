## 240  SDO_GEOR_ADMIN

The `SDO_GEOR_ADMIN` package contains subprograms for administrative operations related to GeoRaster.

For a complete description of this package within the context of Oracle Spatial, see [`SDO_GEOR_ADMIN`](../geors/SDO_GEOR_ADMIN-reference.md) in the Oracle Spatial and Graph GeoRaster Developer's Guide.
