## 261  SEM_RDFCTX

The `SEM_RDFCTX` package contains subprograms for managing extractor policies and semantic indexes created for documents.

For a complete description of this package within the context of Oracle Database semantic technology support, see [`SEM_RDFCTX`](../rdfrm/SEM_RDFCTX-reference.md) in the Oracle Spatial and Graph RDF Semantic Graph Developer's Guide
