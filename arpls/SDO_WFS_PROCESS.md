## 257  SDO_WFS_PROCESS

The `SDO_WFS_PROCESS` package contains subprograms for various processing operations related to support for Web Feature Services.

For a complete description of this package within the context of Oracle Spatial, see [`SDO_WFS_PROCESS`](../spatl/SDO_WFS_PROCESS-reference.md) in the Oracle Spatial and Graph Developer's Guide.
