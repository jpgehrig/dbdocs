## 253  SDO_TOPO_MAP

The `SDO_TOPO_MAP` package contains subprograms for editing Oracle Spatial topologies using a cache (TopoMap object).

For a complete description of this package within the context of Oracle Spatial, see [`SDO_TOPO_MAP`](../topol/SDO_TOPO_MAP-reference.md) in the Oracle Spatial and Graph Topology Data Model and Network Data Model Graph Developer's Guide.
