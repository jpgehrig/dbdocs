## 262  SEM_RDFSA

The `SEM_RDFSA` package contains subprograms for providing fine-grained access control to RDF data, using either a virtual private database (VPD) or Oracle Label Security (OLS).

For a complete description of this package within the context of Oracle Database semantic technology support, see [`SEM_RDFSA`](../rdfrm/SEM_RDFSA-reference.md) in the Oracle Spatial and Graph RDF Semantic Graph Developer's Guide.
