## 242  SDO_GEOR_RA

The `SDO_GEOR_RA` package provides an interface to the `SDO_GEOR_RA` package for performing raster algebra and analytic operations related to GeoRaster.

For a complete description of this package within the context of Oracle Spatial, see [`SDO_GEOR_RA`](../geors/sdo-geor-ra-ref.md) in the Oracle Spatial and Graph GeoRaster Developer's Guide.
