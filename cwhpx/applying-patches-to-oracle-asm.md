After you have upgraded Oracle Grid Infrastructure 19c, you can install individual software patches by downloading them from My Oracle Support.

- [About Individual Oracle Grid Infrastructure Patches](about-individual-one-off-oracle-asm-patches.md)
  Download Oracle ASM individual (one-off) patch and apply it to Oracle Grid Infrastructure using the OPatch Utility.
- [About Oracle Grid Infrastructure Software Patch Levels](about-oracle-asm-software-patch-levels.md)
  Review this topic to understand how to apply patches for Oracle ASM and Oracle Clusterware.
- [Patching Oracle Grid Infrastructure to a Software Patch Level](patching-oracle-asm-to-a-software-patch-level.md)
  Starting with Oracle Grid Infrastructure 12c Release 1 (12.1), a new cluster state, called Rolling Patch, is available. This mode is similar to the existing "Rolling Upgrade" mode in terms of the Oracle ASM operations allowed in this quiesce state.
- [Applying Patches During an Oracle Grid Infrastructure Installation or Upgrade](applying-patches-during-grid-inrastructure-install-or-upgrade.md)
  Starting with Oracle Grid Infrastructure 18c, you can download and apply Release Updates (RUs) and one-off patches during an Oracle Grid Infrastructure installation or upgrade.
