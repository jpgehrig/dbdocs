## 5.34 DBA_HIST_REPORTS_CONTROL

`DBA_HIST_REPORTS_CONTROL` contains control information about the report capture mechanism that automatically captures XML reports to Automatic Workload Repository (AWR).

Reports are captured automatically for components like SQL Monitor and Real-Time Automatic Database Diagnostic Monitor (Real-Time ADDM).

| Column           | Datatype       | NULL | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|:-----------------|:---------------|:-----|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `DBID`           | `NUMBER`       |      | Database ID of the current database for the report                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `EXECUTION_MODE` | `VARCHAR2(12)` |      | Mode of execution of automatic report capture. Possible values:<br>• `REGULAR`: Regular per-minute report capture subject to DBTIME budget<br>• `FULL_CAPTURE`: Report capture will be run per minute without the DBTIME budget constraints and is provided to capture a more comprehensive set of reports<br>NOTE: The `FULL_CAPTURE` mode can be started and ended respectively by executing the `START_REPORT_CAPTURE` and `FINISH_REPORT_CAPTURE` APIs in the `DBMS_AUTO_REPORT` package. At all other times, the execution mode should be `REGULAR`. |
