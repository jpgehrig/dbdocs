## 6.325 USER_ANALYTIC_VIEW_LVL_CLS_AE

`USER_ANALYTIC_VIEW_LVL_CLS_AE` describes the level classifications of the analytic views (across all editions) owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_ANALYTIC_VIEW_LVL_CLS_AE`.

**Note:**

This view is available starting with Oracle Database 19c, Release Update 19.13.
