## 6.332 USER_ANALYTIC_VIEWS_AE

`USER_ANALYTIC_VIEWS_AE` describes the analytic views (across all editions) owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_ANALYTIC_VIEWS_AE`.

**Note:**

This view is available starting with Oracle Database 19c, Release Update 19.13.
