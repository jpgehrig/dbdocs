## 6.182 DM_USER_MODELS

`DM_USER_MODELS` displays information about the models in the user's schema.

| Column             | Datatype        | NULL       | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:-------------------|:----------------|:-----------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `NAME`             | `VARCHAR2(128)` | `NOT NULL` | Name of the model                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `FUNCTION_NAME`    | `VARCHAR2(30)`  |            | Model function:<br>• `association` - Association is a descriptive mining function. An association model identifies relationships and the probability of their occurrence within a data set.<br>• `attribute_importance` - Attribute Importance is a predictive mining function. An attribute importance model identifies the relative importance of an attribute in predicting a given outcome.<br>• `classification` - Classification is a predictive mining function. A classification model uses historical data to predict new discrete or categorical data.<br>• The `classification` function can also be used for anomaly detection. In this case, the SVM algorithm with a null target is used (One-Class SVM).<br>• `clustering` - Clustering is a descriptive mining function. A clustering model identifies natural groupings within a data set.<br>• `feature_extraction` - Feature Extraction is a descriptive mining function. A feature extraction model creates an optimized data set on which to base a model.<br>• `regression` - Regression is a predictive mining function. A regression model uses historical data to predict new continuous, numeric data. |
| `ALGORITHM_NAME`   | `VARCHAR2(30)`  |            | Algorithm used by the model:<br>• `algo_name` - Setting that specifies the algorithm used by the model.<br>• `asso_max_rule_length` - Setting that specifies the maximum length of a rule used by an association model.<br>• `asso_min_confidence` - Setting that specifies the minimum confidence for an association model.<br>• `asso_min_support` - Setting that specifies the minimum support for an association model.<br>• `clas_cost_table_name` - Setting that specifies the name of the cost matrix table for a classification model.<br>• `clas_priors_table_name` - Setting that specifies the name of the prior probability table for NB and ABN models. Decision Tree is the only classification algorithm that does not use priors.<br>• For SVM classification models, this setting specifies the name of a table of weights.<br>• `clus_num_clusters` - Setting that specifies the number of clusters for a clustering model.<br>• `feat_num_features` - Setting that specifies the number of features for a feature selection model.                                                                                                                            |
| `CREATION_DATE`    | `DATE`          | `NOT NULL` | Date on which the model was created                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `BUILD_DURATION`   | `NUMBER`        |            | Duration of the model build process                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `TARGET_ATTRIBUTE` | `VARCHAR2(128)` |            | Attribute designated as the target of a classification model                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `MODEL_SIZE`       | `NUMBER`        |            | Size of the model (in megabytes)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
