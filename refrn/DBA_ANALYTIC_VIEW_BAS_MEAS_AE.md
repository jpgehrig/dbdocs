## 4.56 DBA_ANALYTIC_VIEW_BAS_MEAS_AE

`DBA_ANALYTIC_VIEW_BAS_MEAS_AE` describes the base measures in all analytic views (across all editions) in the database. Its columns are the same as those in `ALL_ANALYTIC_VIEW_BAS_MEAS_AE`.

**Note:**

This view is available starting with Oracle Database 19c, Release Update 19.13.
