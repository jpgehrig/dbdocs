## 8.123 V\$PQ_SESSTAT

`V$PQ_SESSTAT` lists session statistics for parallel queries. After you have run a query or DML operation, you can use the information derived from `V$PQ_SESSTAT` to view the number of worker processes used, and other information for the session and system.

| Column          | Datatype       | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
|:----------------|:---------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `STATISTIC`     | `VARCHAR2(30)` | Name of the statistic:<br>• `Allocation Height` - Requested number of servers per instance<br>• `Allocation Width` - Requested number of instances<br>• `DDL Parallelized` - Number of DDL operations run in parallel<br>• `DFO Trees` - Number of executed DFO trees<br>• `DML Parallelized` - Number of DML operations run in parallel<br>• `DOP` - Degree of parallelism used for the last statement<br>• `Distr Msgs Recv'd` - Number of remote (inter-instance) messages received<br>• `Distr Msgs Sent` - Number of remote (inter-instance) messages sent<br>• `Local Msgs Recv'd` - Number of local (intra-instance) messages received<br>• `Local Msgs Sent` - Number of local (intra-instance) messages sent<br>• `Queries Parallelized` - Number of queries run in parallel<br>• `Server Threads` - Number of PX servers used<br>• `Slave Sets` - Total number of worker sets used for the last statement. For multiple parallelizers in the parallel plan, it is the cumulative count. |
| `LAST_QUERY`    | `NUMBER`       | Value of the statistic for the last operation                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `SESSION_TOTAL` | `NUMBER`       | Value of the statistic for the entire session to this point in time.<br>The value of the statistic for the entire session to this point in time is not maintained for the `DOP`, `Server Threads`, `Allocation Height`, `Allocation Width`, and `Slave Set` statistics.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `CON_ID`        | `NUMBER`       | The ID of the container to which the data pertains. Possible values include:<br>• `0`: This value is used for rows containing data that pertain to the entire CDB. This value is also used for rows in non-CDBs.<br>• `1`: This value is used for rows containing data that pertain to only the root<br>• n: Where n is the applicable container ID for the rows containing data                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
