## 5.298 DBA_ROLLING_STATISTICS

`DBA_ROLLING_STATISTICS` provides a list of rolling operation statistics.

| Column        | Datatype        | NULL | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|:--------------|:----------------|:-----|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `NAME`        | `VARCHAR2(256)` |      | Name of the statistic. Possible values:<br>• `DBMS_ROLLING execution time`<br>• `logical to primary switchover finish time`<br>• `primary services offline for`<br>• `primary to logical switchover start time`<br>• `rolling upgrade finish time`<br>• `rolling upgrade start time`<br>• `time for former primary to fully recover upgrade redo`<br>• `time for former primary to start upgrade redo recovery`<br>• `total time former primary in physical role`<br>• `transient logical creation finish time`<br>• `transient logical creation start time`<br>• `transient logical protection finish time`<br>• `transient logical protection start time`<br>• `user upgrade time` |
| `VALUE`       | `VARCHAR2(256)` |      | Value of the statistic                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `UPDATE_TIME` | `TIMESTAMP(6)`  |      | Time of last update                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
