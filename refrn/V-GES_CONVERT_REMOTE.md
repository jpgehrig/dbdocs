## 7.246 V\$GES_CONVERT_REMOTE

`V$GES_CONVERT_REMOTE` displays values for remote GES enqueue conversions. This view records average convert times, count information, and timed statistics for global enqueue requests.

| Column                 | Datatype       | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|:-----------------------|:---------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `INST_ID`              | `NUMBER`       | ID of the instance                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `CONVERT_TYPE`         | `VARCHAR2(16)` | Conversion type:<br>• `NULL -> SS ` - NULL mode to subshared mode<br>• `NULL -> SX ` - NULL mode to shared exclusive mode<br>• `NULL -> S ` - NULL mode to shared mode<br>• `NULL -> SSX` - NULL mode to subshared exclusive mode<br>• `NULL -> X ` - NULL mode to exclusive mode<br>• `SS -> SX ` - Subshared mode to shared exclusive mode<br>• `SS -> S ` - Subshared mode to shared mode<br>• `SS -> SSX` - Subshared mode to subshared exclusive mode<br>• `SS -> X ` - Subshared mode to exclusive mode<br>• `SX -> S ` - Shared exclusive mode to shared mode<br>• `SX -> SSX` - Shared exclusive mode to subshared exclusive mode<br>• `SX -> X ` - Shared exclusive mode to exclusive mode<br>• `S -> SX ` - Shared mode to shared exclusive mode<br>• `S -> SSX` - Shared mode to subshared exclusive mode<br>• `S -> X ` - Shared mode to exclusive mode<br>• `SSX -> X ` - Sub-shared exclusive mode to exclusive mode |
| `AVERAGE_CONVERT_TIME` | `NUMBER`       | Average conversion time for each type of lock operation (in hundredths of a second)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `CONVERT_COUNT`        | `NUMBER`       | Number of operations                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `CON_ID`               | `NUMBER`       | The ID of the container to which the data pertains. Possible values include:<br>• `0`: This value is used for rows containing data that pertain to the entire CDB. This value is also used for rows in non-CDBs.<br>• `1`: This value is used for rows containing data that pertain to only the root<br>• n: Where n is the applicable container ID for the rows containing data                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
