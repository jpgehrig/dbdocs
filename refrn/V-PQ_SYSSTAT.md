## 8.125 V\$PQ_SYSSTAT

`V$PQ_SYSSTAT` lists system statistics for parallel queries.

After you have run a query or DML operation, you can use the information derived from `V$PQ_SYSSTAT` to view the number of PX (Parallel Execution) servers used, and other information for the system.

| Column      | Datatype       | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
|:------------|:---------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `STATISTIC` | `VARCHAR2(30)` | Name of the statistic:<br>• `DDL Initiated` - Total number of parallel DDL operations that were initiated<br>• `DFO Trees` - Total number of DFO trees executed on this instance<br>• `DML Initiated` - Total number of parallel DML operations that were initiated<br>• `Distr Msgs Recv'd` - Total number of remote (inter-instance) messages received on this instance<br>• `Distr Msgs Sent` - Total number of remote (inter-instance) messages sent on this instance<br>• `Local Msgs Recv'd` - Total number of remote (inter-instance) messages received on this instance<br>• `Local Msgs Sent` - Total number of local (intra-instance) messages sent on this instance<br>• `Queries Initiated` - Total number of parallel queries initiated on this instance<br>• `Queries Queued` - Total number of queued queries on this instance<br>• `Server Sessions` - Total number of operations executed in all PX servers on this instance<br>• `Servers Busy` - Number of currently busy PX servers on this instance<br>• `Servers Cleaned Up` - Total number of PX servers on this instance cleaned up due to process death<br>• `Servers Highwater` - Number of active PX servers on this instance that have partaken in \>= 1 operation so far<br>• `Servers Idle` - Number of currently idle PX servers on this instance<br>• `Servers Shutdown` - Total number of PX servers shutdown on this instance<br>• `Servers Started` - Total number of PX servers started on this instance<br>• `Sessions Active` - Total number of active sessions on this instance |
| `VALUE`     | `NUMBER`       | Value of the statistic                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `CON_ID`    | `NUMBER`       | The ID of the container to which the data pertains. Possible values include:<br>• `0`: This value is used for rows containing data that pertain to the entire CDB. This value is also used for rows in non-CDBs.<br>• `1`: This value is used for rows containing data that pertain to only the root<br>• n: Where n is the applicable container ID for the rows containing data                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
