## 6.318 USER_ANALYTIC_VIEW_HIERS_AE

`USER_ANALYTIC_VIEW_HIERS_AE` describes the hierarchies in the analytic views (across all editions) owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_ANALYTIC_VIEW_HIERS_AE`.

**Note:**

This view is available starting with Oracle Database 19c, Release Update 19.13.
