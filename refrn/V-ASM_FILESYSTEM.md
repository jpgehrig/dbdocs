## 7.74 V\$ASM_FILESYSTEM

`V$ASM_FILESYSTEM` displays information for every mounted Oracle ACFS.

| Column                                 | Datatype         | Description                                                                                                                                                                                                                                                                                                                                                                                                                              |
|:---------------------------------------|:-----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `FS_NAME`                              | `VARCHAR2(1024)` | Mount point (primary key)                                                                                                                                                                                                                                                                                                                                                                                                                |
| `AVAILABLE_TIME`                       | `DATE`           | Mount time or the time that the file system became available again; NULL if the file system is not available                                                                                                                                                                                                                                                                                                                             |
| `BLOCK_SIZE`                           | `NUMBER`         | File system block size (in kilobytes)                                                                                                                                                                                                                                                                                                                                                                                                    |
| `STATE`                                | `VARCHAR2(13)`   | File system status::<br>• `NOT AVAILABLE`<br>• `AVAILABLE`<br>• `OFFLINE` - Either the Oracle ASM instance is down, the disk group has been forced dismounted, or less commonly, a metadata I/O failure occurred or serious metadata corruption was detected. In the case of a metadata I/O failure, the file system is also marked as corrupt. An offline file system can only be unmounted; other attempts at access result in errors. |
| `CORRUPT`                              | `VARCHAR2(5)`    | Indicates whether the file system needs the fixer (`fsck`, `acfschkdsk`) to be run (`TRUE`) or not (`FALSE`)                                                                                                                                                                                                                                                                                                                             |
| `NUM_VOL`                              | `NUMBER`         | Number of volumes in the file system                                                                                                                                                                                                                                                                                                                                                                                                     |
| `TOTAL_SIZE`                           | `NUMBER`         | Total capacity of the file system (in megabytes)                                                                                                                                                                                                                                                                                                                                                                                         |
| `TOTAL_FREE`                           | `NUMBER`         | Total free space in the file system (in megabytes)                                                                                                                                                                                                                                                                                                                                                                                       |
| `TOTAL_SNAP_SPACE_USAGE`               | `NUMBER`         | Total space used by snapshots (in megabytes)                                                                                                                                                                                                                                                                                                                                                                                             |
| `REPLSTATE`                            | `VARCHAR2(7)`    | Replication status:<br>• `NO REPL` - Replication is not initialized<br>• `PRIMARY` - File system is initialized for replication as a primary<br>• `STANDBY` - File system is initialized for replication as a standby                                                                                                                                                                                                                    |
| `RESIZE_STATE`<sup>Foot 1</sup>        | `VARCHAR2(5)`    | Possible resize states:<br>• `NONE` - AutoResize not configured<br>• `AUTO` - Equivalent to AutoResizeEnabled flag<br>• `ERROR` - Equivalent to AutoResizeError flag                                                                                                                                                                                                                                                                     |
| `COMPRESS_STATE`<sup>Foot 1</sup>      | `VARCHAR2(7)`    | Compression status of the file system. Possible values:<br>• `DISABLED` - Compression is not active<br>• `ENABLED` - Compression is active<br>• `PARTIAL` - Compression is disabled, but the file system may contain compressed files                                                                                                                                                                                                    |
| `FROZEN_STATE`<sup>Foot 1</sup>        | `VARCHAR2(5)`    | Indicates whether the filesystem is frozen (`TRUE`) or not (`FALSE`)                                                                                                                                                                                                                                                                                                                                                                     |
| `ACFS_COMPATIBILITY`<sup>Foot 1</sup>  | `VARCHAR2(60)`   | Oracle Release streams where Oracle ACFS has shipped                                                                                                                                                                                                                                                                                                                                                                                     |
| `METADATA_BLOCK_SIZE`<sup>Foot 1</sup> | `NUMBER`         | Metadata block size of the file system. Possible values:<br>• 512<br>• 4096                                                                                                                                                                                                                                                                                                                                                              |
| `CON_ID`                               | `NUMBER`         | The ID of the container to which the data pertains. Possible values include:<br>• `0`: This value is used for rows containing data that pertain to the entire CDB. This value is also used for rows in non-CDBs.<br>• `1`: This value is used for rows containing data that pertain to only the root<br>• n: Where n is the applicable container ID for the rows containing data<br>For this view, the value is always `0`.              |

<sup>Footnote 1</sup> This column is available starting with Oracle Database 19c.
