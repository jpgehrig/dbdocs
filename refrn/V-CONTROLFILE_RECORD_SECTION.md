## 7.149 V\$CONTROLFILE_RECORD_SECTION

`V$CONTROLFILE_RECORD_SECTION` displays information about the control file record sections.

| Column          | Datatype       | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|:----------------|:---------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `TYPE`          | `VARCHAR2(28)` | Identifies the type of record section:<br>• `DATABASE`<br>• `CKPT PROGRESS`<br>• `REDO THREAD`<br>• `REDO LOG`<br>• `DATAFILE`<br>• `FILENAME`<br>• `TABLESPACE`<br>• `TEMPORARY FILENAME`<br>• `RMAN CONFIGURATION`<br>• `LOG HISTORY`<br>• `OFFLINE RANGE`<br>• `ARCHIVED LOG`<br>• `BACKUP SET`<br>• `BACKUP PIECE`<br>• `BACKUP DATAFILE`<br>• `BACKUP REDOLOG`<br>• `DATAFILE COPY`<br>• `BACKUP CORRUPTION`<br>• `COPY CORRUPTION`<br>• `DELETED OBJECT`<br>• `PROXY COPY`<br>• `BACKUP SPFILE`<br>• `DATABASE INCARNATION`<br>• `FLASHBACK LOG`<br>• `RECOVERY DESTINATION`<br>• `INSTANCE SPACE RESERVATION`<br>• `REMOVABLE RECOVERY FILES`<br>• `RMAN STATUS`<br>• `THREAD INSTANCE NAME MAPPING`<br>• `MTTR`<br>• `DATAFILE HISTORY`<br>• `PLUGGED` `IN` `DATAFILE` |
| `RECORD_SIZE`   | `NUMBER`       | Record size in bytes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `RECORDS_TOTAL` | `NUMBER`       | Number of records allocated for the section                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `RECORDS_USED`  | `NUMBER`       | Number of records used in the section                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `FIRST_INDEX`   | `NUMBER`       | Index (position) of the first record                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `LAST_INDEX`    | `NUMBER`       | Index of the last record                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `LAST_RECID`    | `NUMBER`       | Record ID of the last record                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `CON_ID`        | `NUMBER`       | The ID of the container to which the data pertains. Possible values include:<br>• `0`: This value is used for rows containing data that pertain to the entire CDB. This value is also used for rows in non-CDBs.<br>• `1`: This value is used for rows containing data that pertain to only the root<br>• n: Where n is the applicable container ID for the rows containing data                                                                                                                                                                                                                                                                                                                                                                                               |
