## 9.50 V\$SQL_CS_HISTOGRAM

`V$SQL_CS_HISTOGRAM` summarizes the monitoring information stored by adaptive cursor sharing. This information is used to decide whether to enable extended cursor sharing for a query. It is stored in a histogram, whose bucket's contents are exposed by this view.

| Column         | Datatype       | Description                                                                                                                                                                                                                                                                                                                                                                      |
|:---------------|:---------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `ADDRESS`      | `RAW(4 | 8)`   | Address of the handle to the parent for this cursor                                                                                                                                                                                                                                                                                                                              |
| `HASH_VALUE`   | `NUMBER`       | Hash value of the parent statement in the library cache                                                                                                                                                                                                                                                                                                                          |
| `SQL_ID`       | `VARCHAR2(13)` | SQL identifier of the parent cursor in the library cache                                                                                                                                                                                                                                                                                                                         |
| `CHILD_NUMBER` | `NUMBER`       | Number of the child cursor being monitored                                                                                                                                                                                                                                                                                                                                       |
| `BUCKET_ID`    | `NUMBER`       | Bucket number of the monitoring histogram                                                                                                                                                                                                                                                                                                                                        |
| `COUNT`        | `NUMBER`       | Value in this bucket of the histogram                                                                                                                                                                                                                                                                                                                                            |
| `CON_ID`       | `NUMBER`       | The ID of the container to which the data pertains. Possible values include:<br>• `0`: This value is used for rows containing data that pertain to the entire CDB. This value is also used for rows in non-CDBs.<br>• `1`: This value is used for rows containing data that pertain to only the root<br>• n: Where n is the applicable container ID for the rows containing data |
