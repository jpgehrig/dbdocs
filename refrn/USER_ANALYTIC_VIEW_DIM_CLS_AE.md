## 6.310 USER_ANALYTIC_VIEW_DIM_CLS_AE

`USER_ANALYTIC_VIEW_DIM_CLS_AE` describes the classifications of the attribute dimensions in the analytic views (across all editions) owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_ANALYTIC_VIEW_DIM_CLS_AE`.

**Note:**

This view is available starting with Oracle Database 19c, Release Update 19.13.
