## 4.334 DBA_HIER_HIER_ATTR_CLASS_AE

`DBA_HIER_HIER_ATTR_CLASS_AE` describes the classifications of the hierarchical attributes of all hierarchies (across all editions) in the database. Its columns are the same as those in `ALL_HIER_HIER_ATTR_CLASS_AE`.

**Note:**

This view is available starting with Oracle Database 19c, Release Update 19.13.
