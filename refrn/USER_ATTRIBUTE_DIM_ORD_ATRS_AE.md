## 6.362 USER_ATTRIBUTE_DIM_ORD_ATRS_AE

`USER_ATTRIBUTE_DIM_ORD_ATRS_AE` describes the order attributes of the attribute dimensions (across all editions) owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_ATTRIBUTE_DIM_ORD_ATRS_AE`.

**Note:**

This view is available starting with Oracle Database 19c, Release Update 19.13.
