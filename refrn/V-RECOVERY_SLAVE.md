## 8.160 V\$RECOVERY_SLAVE

`V$RECOVERY_SLAVE` is used to track database media recovery processes to monitor their performance statistics and analyze a media recovery session.

| Column       | Datatype        | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|:-------------|:----------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `START_TIME` | `DATE`          | Start time of the recovery process                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `TYPE`       | `VARCHAR2(64)`  | Type of recovery process being performed:<br>• `MEDIA RECOVERY Apply SLAVE`<br>• `MEDIA RECOVERY Merge Slave`<br>• `SERIAL MEDIA RECOVERY`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `ITEM`       | `VARCHAR2(32)`  | Item being measured.<br>When `TYPE` is `MEDIA RECOVERY Apply SLAVE`, the possible values are:<br>• `Recovery ID`<br>• `Process ID`<br>• `Number of Redo Cache Full`<br>• `Number of Redo Cache Copy`<br>• `Number of CV Cached`<br>• `CV Applied OK`<br>• `CV Applied Stuck`<br>• `CV Applied Repair`<br>• `CV Applied Corrupt`<br>• `CV Applied Ckpt`<br>• `CV Applied Reapplied`<br>• `Total CV Processed Size`<br>• `Total CV Applied`<br>• `Number of Buffer Cache Full`<br>• `Number of Buffer Retries`<br>• `Number of Max Reads Issued`<br>• `Number of Unrcv Condition`<br>• `Number of Influx Buffer Flushed`<br>• `Number of Reap Request`<br>• `Number of Reap Wait IO`<br>• `Number of Reap No Buffer`<br>• `Number of Wait All Read`<br>• `Number of Buffer Pinged`<br>• `Buffer Ping Time`<br>• `Read Issue Time`<br>• `Number of Read Request Issued`<br>When `TYPE` is `MEDIA RECOVERY Merge Slave`, the possible values are:<br>• `Recovery ID`<br>• `Process ID`<br>• `Number of Redo Cache Full`<br>• `Number of Redo Cache Copy`<br>• `Number of CV Cached`<br>• `Total Redo Read Bytes`<br>• `Total CV Parsed`<br>When `TYPE` is `SERIAL MEDIA RECOVERY`, the possible values include values from the other two `TYPE`s. |
| `UNITS`      | `VARCHAR2(32)`  | The units of measurement for each item                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `SOFAR`      | `NUMBER`        | Amount of work done so far                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `TOTAL`      | `NUMBER`        | Total amount of work expected                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `COMMENTS`   | `VARCHAR2(248)` | Miscellaneous notes, which may display the recovery ID and process ID for current recovery session                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `CON_ID`     | `NUMBER`        | The ID of the container to which the data pertains. Possible values include:<br>• `0`: This value is used for rows containing data that pertain to the entire CDB. This value is also used for rows in non-CDBs.<br>• `1`: This value is used for rows containing data that pertain to only the root<br>• n: Where n is the applicable container ID for the rows containing data                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
