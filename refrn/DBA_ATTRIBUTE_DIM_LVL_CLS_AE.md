## 4.145 DBA_ATTRIBUTE_DIM_LVL_CLS_AE

`DBA_ATTRIBUTE_DIM_LVL_CLS_AE` describes the level classifications of all attribute dimensions (across all editions) in the database. Its columns are the same as those in `ALL_ATTRIBUTE_DIM_LVL_CLS_AE`.

**Note:**

This view is available starting with Oracle Database 19c, Release Update 19.13.
