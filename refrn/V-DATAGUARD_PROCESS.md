## 7.167 V\$DATAGUARD_PROCESS

`V$DATAGUARD_PROCESS` displays one row for each Oracle Data Guard process that is currently running.

| Column        | Datatype       | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:--------------|:---------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `NAME`        | `VARCHAR2(5)`  | Name of the process whose information is being reported. Some of the possible values include:<br>• ARCn - Archiver process<br>• DTS - Data transport process<br>• FAL - File/announce process<br>• LGWR - Log Writer Process<br>• MRP0 - Detached recovery server process<br>• NSSn - SYNC Redo Transport process<br>• ORA - Foreground process<br>• RFS - Remote file server<br>• RMI - Remote message process<br>• TMON - Redo Transport Process monitor<br>• TTnn - Redo Transport Worker Process                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `PID`         | `VARCHAR2(24)` | Operating system process identifier of the process                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `TYPE`        | `VARCHAR2(3)`  | Indicates which Oracle subsystem created the process. Possible values:<br>• KSB<br>• KSV<br>• NET<br>• UNK                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `ROLE`        | `VARCHAR2(24)` | Role of the process. Possible values:<br>• test<br>• async ORL multi<br>• async ORL single<br>• async SRL multi<br>• async SRL single<br>• log writer<br>• sync<br>• archive redo<br>• archive local<br>• archive gap<br>• RFS async<br>• RFS sync<br>• RFS archive<br>• RFS gap<br>• RFS SMON<br>• data transport<br>• data receive<br>• redo transport monitor<br>• heartbeat redo informer<br>• process kill<br>• post role transition<br>• gap manager<br>• update TMI<br>• RFS ping<br>• FAL gap<br>• FAL announce<br>• failover<br>• switchover<br>• remote failover<br>• remote switchover<br>• redo transport timer<br>• announce request<br>• managed recovery<br>• recovery<br>• controlfile update<br>• broker monitor<br>• broker worker<br>• broker net slave<br>• broker instance slave<br>• fast-start failover ping<br>• recovery coordinator<br>• recovery logmerger<br>• recovery apply slave<br>• recovery sending slave<br>• recovery receiving slave<br>• redo transport test<br>• temporary<br>• datafile pre-create<br>• redo log management<br>• UNKNOWN |
| `PROC_TIME`   | `TIMESTAMP(0)` | Timestamp of when the process started or registered for inclusion in this fixed view                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `TASK_TIME`   | `TIMESTAMP(0)` | Timestamp of when the first task of the process was requested                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `TASK_DONE`   | `VARCHAR2(1)`  | Indicates whether the task performed by the process is done (`Y`) or not (`N`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `ACTION`      | `VARCHAR2(12)` | Current action of the process. Possible values can include:<br>• `ANNOUNCING`<br>• `APPLYING_LOG`<br>• `ATTACHED`<br>• `CLOSING`<br>• `CONNECTED`<br>• `ERROR`<br>• `IDLE`<br>• `OPENING`<br>• `PROCESSING`<br>• `RECEIVING`<br>• `REGISTERING`<br>• `STARTING`<br>• `TERMINATING`<br>• `UNKNOWN`<br>• `UNUSED`<br>• `WAIT_FOR_GAP`<br>• `WAIT_FOR_LOG`<br>• `WRITING`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `CLIENT_PID`  | `NUMBER`       | For RFS and DTS processes, the PID of the process communicating with this process                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `CLIENT_ROLE` | `VARCHAR2(16)` | For RFS and DTS processes, the role of the process communicating with this process.<br>Possible values can include:<br>• none<br>• async ORL multi<br>• async ORL single<br>• async SRL multi<br>• async SRL single<br>• log writer<br>• sync<br>• archive redo<br>• archive gap<br>• data transport<br>• gap manager<br>• failover<br>• switchover<br>• announce request<br>• managed recovery<br>• recovery<br>• UNKNOWN                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `GROUP#`      | `NUMBER`       | Group number of the log that the process is operating upon                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `RESETLOG_ID` | `NUMBER`       | Resetlog ID (branch) of the log that the process is operating upon                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `THREAD#`     | `NUMBER`       | Thread number that the process is operating upon                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `SEQUENCE#`   | `NUMBER`       | Sequence number that the process is operating upon                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `BLOCK#`      | `NUMBER`       | Starting block number that the process is operating upon                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `BLOCK_COUNT` | `NUMBER`       | Number of blocks that the process is operating upon                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `DELAY_MINS`  | `NUMBER`       | Archived redo log delay interval in minutes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `DEST_ID`     | `NUMBER`       | Destination ID that the process is currently operating upon                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `DEST_MASK`   | `NUMBER`       | Mask of all destination IDs that the process will operate upon, where:<br>• Bit 0 is LOG_ARCHIVE_DEST1<br>• Bit 1 is LOG_ARCHIVE_DEST2<br>• Bit 2 is LOG_ARCHIVE_DEST3<br>and so on.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ` DBID`       | `NUMBER`       | Database ID of the redo that the process is operating upon                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `DGID`        | `NUMBER`       | Data Guard ID that the process must communicate with                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `INSTANCE`    | `NUMBER`       | Instance number that the process must communicate with at the specified DGID                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `STOP_STATE`  | `VARCHAR2(7)`  | Indicates the method by which the process has been requested to stop:<br>• NOW - Requested to stop immediately and exit<br>• SOON - Requested to stop on next log and exit<br>• COMMIT - Requested to write remaining redo and exit<br>• N/A - No request to stop                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `CON_ID`      | `NUMBER`       | The ID of the container to which the data pertains. Possible values include:<br>• `0`: This value is used for rows containing data that pertain to the entire CDB. This value is also used for rows in non-CDBs.<br>• `1`: This value is used for rows containing data that pertain to only the root<br>• n: Where n is the applicable container ID for the rows containing data                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

**Note:**

Oracle recommends that you use this view instead of `V$MANAGED_STANDBY`.
