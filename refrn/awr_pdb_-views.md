## 2.2 AWR_PDB\_\* Views

The AWR_PDB views show the local Automatic Workload Repository (AWR) data present on a CDB root or a PDB from where the AWR_PDB views are accessed.

The AWR_PDB views on a CDB root show the AWR data stored on the CDB root.

The AWR_PDB views on a PDB show the AWR data stored on that PDB.
