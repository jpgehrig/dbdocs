## 4.152 DBA_ATTRIBUTE_DIMENSIONS_AE

`DBA_ATTRIBUTE_DIMENSIONS_AE` describes all attribute dimensions (across all editions) in the database. Its columns are the same as those in `ALL_ATTRIBUTE_DIMENSIONS_AE`.

**Note:**

This view is available starting with Oracle Database 19c, Release Update 19.13.
