## 6.363 USER_ATTRIBUTE_DIM_ORDER_ATTRS

`USER_ATTRIBUTE_DIM_ORDER_ATTRS` describes the order attributes of the attribute dimensions owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_ATTRIBUTE_DIM_ORDER_ATTRS`.
