## 7.36 V\$ARCHIVE_DEST_STATUS

`V$ARCHIVE_DEST_STATUS` displays run time and configuration information for the archived redo log destinations.

The information in this view does not persist across an instance shutdown.

| Column                   | Datatype        | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|:-------------------------|:----------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

| `DEST_NAME`              | `VARCHAR2(256)` | Log archive destination parameter name                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `STATUS`                 | `VARCHAR2(9)`   | Current status of the destination:<br>• `ALTERNATE` - Destination is in an alternate state<br>• `BAD` `PARAM` - Parameter has errors<br>• `DEFERRED` - Manually disabled by the user<br>• `DISABLED` - Disabled after error<br>• `ERROR` - Error during open or copy<br>• `FULL` - Exceeded quota size for the destination<br>• `IDLE` - Destination is idle<br>• `INACTIVE` - No destination information<br>• `VALID` - Initialized and available                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |

| `RECOVERY_MODE`          | `VARCHAR2(34)`  | Current apply mode at the archival destination:<br>• `IDLE` - Managed recovery is not active<br>• `LOGICAL` `APPLY` - SQL Apply<br>• `LOGICAL` `REAL` `TIME` `APPLY` - Real time SQL Apply<br>• `MANAGED` - Managed recovery is active. In this recovery mode, users cannot query data on the standby.<br>• `MANAGED` `REAL` `TIME` `APPLY` - In this recovery mode, log apply services recover redo data from standby redo logs at the same time the logs are being written to, as opposed to recovering redo from archived redo logs when a log switch occurs. In this recovery mode, users cannot query data on the standby.<br>• `MANAGED` `REAL` `TIME` `APPLY` `WITH` `QUERY` - In this recovery mode, log apply services recover redo data from standby redo logs at the same time the logs are being written to, as opposed to recovering redo from archived redo logs when a log switch occurs. In a non-CDB, this mode is used when the database is open, and users can query data on the standby. In a CDB, this value is used when one or more PDBs in the CDB are open, and users can query data on the standby.<br>• `MANAGED` `WITH` `QUERY` - Managed recovery is active in this recovery mode. In a non-CDB, this value is used when the database is open, and users can query data on the standby. In a CDB, this value is used when one or more PDBs in the CDB are open, and users can query data on the standby. |

| `SYNCHRONIZATION_STATUS` | `VARCHAR2(22)`  | Possible values for this column are as follows:<br>• `CHECK` `CONFIGURATION` - Synchronization with this destination is not possible because this database is either not in `MAXIMUM` `PROTECTION` or `MAXIMUM` `AVAILABILITY` data protection mode, or the `LOG_ARCHIVE_DEST_``n` parameter associated with this destination has not been configured with the `SYNC` and `AFFIRM` attributes.<br>• `CHECK` `CONNECTIVITY` - One or more instances of this database cannot send redo data to this destination.<br>• `CHECK` `STANDBY` `REDO` `LOG` - The standby redo log at this destination is configured improperly.<br>• `DESTINATION` `HAS` `A` `GAP` - This destination is missing redo data needed for synchronization with this database.<br>• `OK` - This destination is synchronized with this database.<br>• `STATUS` `NOT` `AVAILABLE` - Synchronization status is not available.<br>See Also: [Oracle Data Guard Concepts and Administration](../sbydb/oracle-data-guard-redo-transport-services.md) for more information about redo transport configuration                                                                                                                                                                                                                                                                                                                                                                                                                      |

It may be possible to resolve the gap by fetching the missing redo from another destination.<br>• `LOG` `SWITCH` `GAP` - Destination has not yet received all of the redo from the previous log file.<br>• `NO` `GAP` - Destination does not have a redo gap.<br>• `RESOLVABLE` `GAP` - Destination has a redo gap that can be automatically resolved by fetching the missing redo from this database.<br>• `UNRESOLVABLE` `GAP` - Destination has a redo gap that cannot be automatically resolved by fetching the missing redo from this database and there are no other destinations from which redo can be fetched.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
