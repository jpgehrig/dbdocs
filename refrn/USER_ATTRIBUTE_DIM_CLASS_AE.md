## 6.347 USER_ATTRIBUTE_DIM_CLASS_AE

`USER_ATTRIBUTE_DIM_CLASS_AE` describes the classifications of the attribute dimensions (across all editions) owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_ATTRIBUTE_DIM_CLASS_AE`.

**Note:**

This view is available starting with Oracle Database 19c, Release Update 19.13.
