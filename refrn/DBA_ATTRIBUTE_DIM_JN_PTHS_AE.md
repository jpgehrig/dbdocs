## 4.134 DBA_ATTRIBUTE_DIM_JN_PTHS_AE

`DBA_ATTRIBUTE_DIM_JN_PTHS_AE` describes the join paths for all attribute dimensions (across all editions) in the database. Its columns are the same as those in `ALL_ATTRIBUTE_DIM_JN_PTHS_AE`.

**Note:**

This view is available starting with Oracle Database 19c, Release Update 19.13.
