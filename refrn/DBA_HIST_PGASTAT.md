## 5.25 DBA_HIST_PGASTAT

`DBA_HIST_PGASTAT` displays historical PGA memory usage statistics as well as statistics about the automatic PGA memory manager when it is enabled.

This view contains snapshots of `V$PGASTAT`.

| Column            | Datatype       | NULL       | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|:------------------|:---------------|:-----------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `SNAP_ID`         | `NUMBER`       | `NOT NULL` | Unique snapshot ID                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `DBID`            | `NUMBER`       | `NOT NULL` | Database ID for the snapshot                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `INSTANCE_NUMBER` | `NUMBER`       | `NOT NULL` | Database instance number                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `NAME`            | `VARCHAR2(64)` | `NOT NULL` | Name of the statistic:<br>• `aggregate PGA auto target`<br>• `aggregate PGA target parameter`<br>• `bytes processed`<br>• `cache hit percentage`<br>• `extra bytes read/written`<br>• `global memory bound`<br>• `max processes count`<br>• `maximum PGA allocated`<br>• `maximum PGA used for auto workareas`<br>• `maximum PGA used for manual workareas`<br>• `over allocation count`<br>• `PGA memory freed back to OS`<br>• `process count`<br>• `recompute count (total)`<br>• `total freeable PGA memory`<br>• `total PGA allocated`<br>• `total PGA inuse`<br>• `total PGA used for auto workareas`<br>• `total PGA used for manual workareas`<br>See Also: `V$PGASTAT` for descriptions of the statistics |
| `VALUE`           | `NUMBER`       |            | Statistic value                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `CON_DBID`        | `NUMBER`       |            | The database ID of the PDB for the sampled session                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `CON_ID`          | `NUMBER`       |            | The ID of the container that `CON_DBID` identifies. Possible values include:<br>• `0`: This value is used for rows containing data that pertain to the entire CDB. This value is also used for rows in non-CDBs.<br>• `1`: This value is used for rows containing data that pertain to only the root<br>• n: Where n is the applicable container ID for the rows containing data                                                                                                                                                                                                                                                                                                                                   |
