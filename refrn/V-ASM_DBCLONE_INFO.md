## 7.63 V\$ASM_DBCLONE_INFO

`V$ASM_DBCLONE_INFO` shows the relationship between the parent database and point-in-time database clones.

| Column                  | Datatype        | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
|:------------------------|:----------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `GROUP_NUMBER`          | `NUMBER`        | Disk group number                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `DBCLONE_NAME`          | `VARCHAR2(128)` | Name of the point-in-time database clone                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `MIRRORCOPY_NAME`       | `VARCHAR2(128)` | Name of the mirror copy associated with the database clone                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `DBCLONE_STATUS`        | `VARCHAR2(128)` | Status of the database clone. Possible values:<br>• `PREPARING` — The process to prepare the database for splitting has started, but the database is not yet ready to be split.<br>• `PREPARED` — The preparation process is complete and the database is ready to be split.<br>• `SPLITTING` — The process to split the database files has started.<br>• `SPLIT COMPLETED` — The database has been split.<br>• `DROPPING` — The process to drop the prepared database clone has started.<br>• `FAILED` — The clone operation has failed. The incomplete clone will be dropped. |
| `PARENT_DBNAME`         | `VARCHAR2(128)` | Name of the parent database                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `PARENT_FILEGROUP_NAME` | `VARCHAR2(128)` | Name of the file group associated with the parent database                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `CON_ID`                | `NUMBER`        | The ID of the container to which the data pertains. Possible values include:<br>• `0`: This value is used for rows containing data that pertain to the entire CDB. This value is also used for rows in non-CDBs.<br>• `1`: This value is used for rows containing data that pertain to only the root<br>• n: Where n is the applicable container ID for the rows containing data                                                                                                                                                                                                |
