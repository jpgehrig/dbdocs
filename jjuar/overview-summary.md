# Universal Connection Pool

**Packages**

| Package                                                               | Description                                                                                                       |
|-----------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------|
| [oracle.ucp](oracle/ucp/package-summary.md)                           | Includes both required and optional callback interfaces that are used to implement connection pool features.      |
| [oracle.ucp.admin](oracle/ucp/admin/package-summary.md)               | Defines interfaces for administering Universal Connection Pool instances, including JMX support.                  |
| [oracle.ucp.jdbc](oracle/ucp/jdbc/package-summary.md)                 | Includes various interfaces and classes used by applications to work with JDBC connections and a connection pool. |
| [oracle.ucp.jdbc.oracle](oracle/ucp/jdbc/oracle/package-summary.md)   | Includes various runtime statistics for the Universal Connection Pool that are specific to Oracle JDBC resources. |
| [oracle.ucp.util.logging](oracle/ucp/util/logging/package-summary.md) | Includes a Universal Connection Pool custom formatter for log messages.                                           |
