## O

[oracle.ucp](../oracle/ucp/package-summary.md) - package oracle.ucp
Includes both required and optional callback interfaces that are used to implement connection pool features.

[oracle.ucp.admin](../oracle/ucp/admin/package-summary.md) - package oracle.ucp.admin
Defines interfaces for administering Universal Connection Pool instances, including JMX support.

[oracle.ucp.jdbc](../oracle/ucp/jdbc/package-summary.md) - package oracle.ucp.jdbc
Includes various interfaces and classes used by applications to work with JDBC connections and a connection pool.

[oracle.ucp.jdbc.oracle](../oracle/ucp/jdbc/oracle/package-summary.md) - package oracle.ucp.jdbc.oracle
Includes various runtime statistics for the Universal Connection Pool that are specific to Oracle JDBC resources.

[oracle.ucp.util.logging](../oracle/ucp/util/logging/package-summary.md) - package oracle.ucp.util.logging
Includes a Universal Connection Pool custom formatter for log messages.

[OracleJDBCConnectionPoolStatistics](../oracle/ucp/jdbc/oracle/OracleJDBCConnectionPoolStatistics.md) - Interface in [oracle.ucp.jdbc.oracle](../oracle/ucp/jdbc/oracle/package-summary.md)
Various runtime statistics for the Universal Connection Pool that are specific to Oracle JDBC resources.
